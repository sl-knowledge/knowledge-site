**认知失衡是一种有价值的学习触发机制，但不能把它视为所有学习的必要条件，也不能把它当作有效学习的充分条件。**

遇到与预期不符的事实，学习者可能产生求知欲，也可能困惑、回避，或把新事实归为例外。即使产生了好奇心，也不代表一定能够形成正确理解、长期记忆和迁移能力。

因此，需要区分两个问题：怎样使学习者发现一个值得追问的问题；怎样使这种追问转化为有效、持续、可以积累的学习。本文围绕一门帮助学习者理解和探索语言的短课，讨论这两个问题的条件关系。以下教学安排与检验方案是工作性设计，尚未证明整套方法具有额外效果。

<a id="course-objective"></a>

## 一、课程目标：获得继续探索语言的方法

这门短课的重点，是让学习者在接触陌生语言现象时，知道如何观察、提出有依据的解释，并检验和修正理解。完成短课不等于掌握一门语言，也不意味着已经具备大量词汇、准确发音或流利表达。

课程中的 Framework 指组织问题的初始框架；Generator 指把共同任务、可采用的表达手段和约束联系起来、用于提出解释与预测的生成性理解。它不能只是一句宽泛的口号，而应能缩小可能性空间，并说明哪些事实会要求修正它。

例如，语言需要传递意义，不同语言可以采用不同的表达方式。这个起点能够帮助学习者比较语言，但不能唯一推导出中文实际采用的语序、某个名词搭配的量词，或某个表达是否自然。这些还涉及具体语言的约定、历史和使用习惯。

Genotype（基因型）与 Phenotype（表现型）可以作为结构类比：前者对应共同任务、约束及生成关系，后者对应具体词汇、句子、发音和表达习惯。这不是生物学机制的主张，也不意味着固定的 Generator 能唯一决定每一个语言现象。

声调系统怎样利用音高区分意义，属于可以探索的结构；某个字实际读第几声，属于需要学习的具体事实。短课可以优先处理前者，同时提供理解结构所需的基本事实。此后的词汇、语音和表达训练仍然必要。

**核心目标是：通过有限而精确的引导，帮助学习者建立一个可修正、可继续扩展的 Generator，使其在课程结束后能够继续观察、推理、提问和学习。** 能否迁移到后续学习，是需要检验的假设。

<a id="disequilibrium-and-curiosity"></a>

## 二、认知失衡怎样产生问题

本文所说的认知失衡，是已有预期与观察结果不符时出现的理解缺口。它不同于笼统的认知偏差，也不等于好奇心本身。

例如，熟悉葡萄牙语的学习者可能预期，动词形式应随人称和时态变化。接触中文后，发现这种预期不能直接沿用，可能出现不同反应：

| 反应 | 可能的表现 |
| --- | --- |
| 发现缺口并追问 | 开始检查原来的预期依据，以及时间、人称等信息怎样表达 |
| 回避 | 认为差异太难理解，只记住当前形式 |
| 局部修补 | 把中文当作一个特殊例外，保留原来的总体框架 |
| 框架修正 | 开始比较不同语言完成相同交流任务的不同方式 |

这些是示意性的可能反应，不是课堂实验结果。发现差异不会自动带来最后一种变化；引导、基本事实和可供比较的替代解释，都是需要考虑的条件。[1](#ref-1)

同样的知识缺口，对不同学习者可能具有不同吸引力。问题是否与当前目标有关、是否能够理解、是否看得见继续探索的方向，都可能影响后续行为。[3](#ref-3) [4](#ref-4)

认知失衡也不是持续学习的唯一入口。成功解释一个新现象、正确预测一个未见过的表达，同样可能形成继续探索的动力。成功预测与预测失败各在什么条件下更有效，仍需比较。

<a id="teaching-cycle"></a>

## 三、从初始框架到独立探索

教学流程可与[框架驱动的学习循环](./framework-driven-learning.md)配合使用，各部分承担不同工作：

| 环节 | 主要作用 | 需要观察的表现 |
| --- | --- | --- |
| 建立初始 Framework | 从熟悉材料出发，认识母语只是多种实现方式之一 | 学习者能说明原来预期来自什么 |
| 提供最小 Generator 与必要事实 | 组织共同任务、表达手段和约束，缩小搜索空间 | 能提出少数有依据的解释，而非任意猜测 |
| 形成预测并观察差异 | 使理解缺口具体可见 | 能指出预期与观察究竟哪里不同 |
| 引导、对比与反馈 | 提供可区分的例子，检验解释并修正框架 | 能说明哪些观察支持或反对一个解释 |
| 新情境检验 | 检查是否掌握了可继续使用的方法 | 能处理未教过的材料，并逐步减少提示 |
| 练习、应用与积累 | 把理解转化为较稳定的知识和实际能力 | 保持、准确率与使用能力得到单独记录 |

认知失衡是其中帮助发现和修正 Generator 的一种机制，不要求每一轮都刻意制造冲突。当解释已经足够清楚、主要任务变成提高速度和准确率时，教学可以转向练习与巩固。

### 目标语言可以变化，入口需要考虑母语

课程可以使用中文、葡萄牙语或其他语言作为材料。共同的研究对象，是语言怎样在共同任务与不同约束下形成多种表达方式。

但材料可以跨语言，不等于教学入口可以忽略母语。预测需要已有框架；母语往往是现成的起点。底层目标可以相同，用来形成预期和对比的材料则需要根据学习者已有知识调整。

### 对比设计需要教，提示需要逐步撤去

面对两个形式不同的表达，学习者可能只注意到词尾或语序不同，却不知道怎样判断差异由什么条件造成。设计最小差异对比应作为显式的教学内容：尽量保持其他条件相同，改变一个待研究条件，观察表达如何变化。

教学可以先提供示范，再让学习者补全对比，最后要求其独立选择有区分力的例子。教师提出最初的问题，并不妨碍独立探索的目标；关键是学习者以后能否说明为什么这样比较，并在新情境中自行使用。

<a id="risks-and-boundaries"></a>

## 四、八项风险与适用边界

| 潜在问题 | 为什么会出现 | 设计上如何处理 |
| --- | --- | --- |
| 1. 没有足够知识，产生不了预测 | 新手不知道有哪些可能性，预测只是随机猜测 | 提供最小知识核、基本事实与少量例子 |
| 2. 差异太大，学习者放弃探索 | 新信息难以与已有知识联系 | 调整任务难度，提供能够继续探索的中间步骤 |
| 3. 把异常当成例外 | 局部修补可能比重建框架更省力 | 比较不同实现，并检验原框架能否解释新材料 |
| 4. 有问题却不想追问 | 兴趣、目标、能力感及预期投入不同 | 使问题与学习目标有关，让每课产生可感知的理解或使用进展 |
| 5. 推导出错误规律 | 少量例子可能同时支持多种解释 | 提供反例、必要事实和可靠反馈 |
| 6. Generator 过于宽泛 | 可以事后兼容所有结果，却不能区分解释 | 要求产生具体预测，记录会迫使其修正的事实 |
| 7. 理解原理却不能熟练使用 | 概念理解、知识记忆和技能自动化是不同任务 | 明确短课与后续训练的分工，安排提取、间隔练习和实际应用 |
| 8. 表现过度依赖教师 | 暗示、提示或代做推理可能掩盖独立能力 | 记录提示程度，逐步撤去支撑，单独测试未教材料 |

### 理解、记忆与自动化需要分别评价

能够解释中文与葡萄牙语的结构差异，不等于能够听懂快速中文。概念理解、具体知识积累和技能自动化，都需要相应训练与检验。[6](#ref-6) [7](#ref-7)

短课不以覆盖全部语言事实为目标，不能据此把所有未掌握的词汇都视为课程失败；同样，也不能以“教的是方法”为由免除对后续实际学习效果的检验。

### 接受统一思想，不等于掌握生成机制

学习者能够复述“不同语言解决共同交流任务”，仍可能无法解释陌生句子的差异。评价应要求具体解释、预测、比较和纠错，避免仅凭理解感作判断。解释深度错觉研究为这个区分提供了相关依据。[5](#ref-5)

### 适用性应按学习任务区分

| 学习任务 | 本方法可承担的工作 | 仍需补充的条件 |
| --- | --- | --- |
| 科学概念、因果机制、物理原理 | 构造预测、比较解释和反例 | 可靠观察、具体学科知识与反馈 |
| 经济、历史机制和复杂系统 | 比较不同机制及其条件 | 处理竞争解释与证据不确定性 |
| 数学概念、建模与解题 | 利用已有结构生成问题和推导 | 正确证明、练习与方法边界 |
| 外语语法和表达结构 | 发现表达手段与约束关系 | 具体语言的约定和实际使用材料 |
| 词汇、汉字和固定事实 | 帮助组织、联结待学内容 | 记忆、提取与间隔练习 |
| 发音、运动技能和快速反应 | 帮助理解任务与反馈 | 示范、及时反馈与大量实践 |

这张表是任务分工的初步分析，不是跨领域教学效果的实验结论。认知失衡可能更适合需要调整理解的阶段，不能由此推定它适合全部学习任务。

<a id="evaluation"></a>

## 五、怎样评价课程是否有效

短课首先评价学习者能否继续探索，而不只评价当场记住了多少词汇。主要指标可以包括：

| 要检验的能力 | 具体观察方式 |
| --- | --- |
| 修正原有框架 | 是否仍把其他语言当作母语规则的例外，能否说明原预期需要怎样调整 |
| 理解 Generator | 能否解释不同语言怎样完成相同的交流任务，并指出解释的边界 |
| 缩小搜索空间 | 遇到陌生结构，能否提出少数有依据、可比较的解释 |
| 主动探索 | 能否设计对比例子、请求有用信息和检验猜想 |
| 减少对提示的依赖 | 面对未教过的现象，能否独立使用方法 |
| 为后续学习做准备 | 学习同一批新材料时，理解速度、准确率及后续保持是否改善 |

最后一项把课堂中的方法表现，与课程以后的学习连接起来。Bransford 与 Schwartz 的“为未来学习做准备”视角，强调通过后续学习的速度或质量观察迁移，而不只看即时独立解题。[8](#ref-8)

例如，可以让短课组与对照组在相同条件下学习一批未教过的量词或句式，比较理解、学习所需时间和延迟后的表现。课堂上能分析一个例子，不能单独证明已经获得长期或跨领域迁移能力。

<a id="experimental-design"></a>

## 六、检验认知失衡是否带来额外效果

一个需要区分的问题是：学习进步主要来自初始框架和良好引导，还是刻意安排的预测与认知冲突产生了额外效果？可以采用四组设计：

| 组别 | 有明确的初始框架教学 | 有刻意设计的预测与冲突活动 |
| --- | --- | --- |
| A：常规规则教学 | 否 | 否 |
| B：框架教学 | 是 | 否 |
| C：预测冲突教学 | 否 | 是 |
| D：完整安排 | 是 | 是 |

这里“无框架教学”指没有明确安排本文提出的框架环节，不表示学习者完全没有已有框架。比较时应尽量保持教学时间、知识内容、材料与反馈质量相当，并合理分组、记录实施差异及学习者起点。

- B 与 A 的比较，用于估计明确框架教学在相应条件下的增量。
- D 与 B 的比较，用于估计已有框架教学时，预测与冲突活动是否带来额外效果。
- C 与 A、D 与 C 的比较，可帮助检查这种增量是否随框架条件变化。

如果 D 没有显示优于 B 的效果，就不能直接声称刻意制造认知失衡是必要环节；还需考虑样本、测量和实际教学实施。即使出现差异，分组首先检验的是教学安排，不能仅凭差异就确认具体心理机制。

应在学习后立即、几天后及更长时间后，分别观察新题迁移、后续学习、记忆保持、提问质量和继续学习的意愿。任务表现还应记录教师提示程度，避免把教师完成的推理计入学习者的独立能力。

<a id="conclusion"></a>

## 七、保留什么，检验什么

值得保留的核心是：先建立能够形成有依据预期的框架，再通过观察、对比、引导和反馈，使新事实成为修正理解的机会。

需要检验的是：短课能否使学习者在结束后继续独立探索；刻意设计的认知失衡是否提供额外效果；这种效果在什么任务、知识起点和引导条件下成立。

**课程的目标是提高解释、预测和解决问题的能力。认知失衡是其中一种手段，目标、兴趣、成功体验和练习也可以支持学习。**

<a id="related-research"></a>

## 八、与已有研究的关系

### 概念转变与矛盾信息

Potvin 的综述研究科学学习者面对矛盾信息时的反应，提供了分析认知冲突与概念变化的背景。[1](#ref-1)

Pacaci、Ustun 与 Ozdemir 的荟萃分析纳入218项研究、18,051名学生，比较科学教育中的认知冲突、认知桥接和本体类别转移等策略，报告总体正向效果及研究间差异。[2](#ref-2) 这些结果针对所纳入的科学教育研究，不能直接证明本文语言短课的具体顺序或整套设计有效。

### 信息缺口与学习动机

Loewenstein 用被感知到的知识或理解缺口解释好奇心。[3](#ref-3) Ryan 与 Deci 的自我决定理论讨论自主、能力感和关系支持对动机的意义。[4](#ref-4) 本文据此把“发现缺口”与“愿意继续探索”分开处理；这里提出的具体引导安排仍需单独检验。

### 理解感、练习与后续学习

Rozenblit 与 Keil 的研究表明，主观理解感可能高于实际解释能力。[5](#ref-5) Dunlosky 等人的综述，以及 Donoghue 与 Hattie 的荟萃分析，为练习测试和分散练习提供了相关证据。[6](#ref-6) [7](#ref-7) Bransford 与 Schwartz 则提供了评价后续学习准备的一种迁移视角。[8](#ref-8)

这些研究支持区分不同学习任务和评价方式，不构成本文所有教学安排的直接验证。本文的整合、课程分工与四组检验方案，保留工作性设计的地位。
