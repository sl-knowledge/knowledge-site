*一篇关于研究如何逐渐形成的短文｜2026年11月6日*

<a id="bunge-background"></a>

## 先认识一下邦格

马里奥·邦格（Mario Bunge，1919—2020）是出生于阿根廷、后来在加拿大麦吉尔大学任教的**物理学家和科学哲学家**。他研究过物理学，也长期思考一个更大的问题：我们究竟应该怎样认识真实世界？他一生写下大量著作，其中历时多年完成的八卷本《基础哲学论》（*Treatise on Basic Philosophy*），试图把世界的构成、科学知识、研究方法和伦理等问题联系起来。

邦格不满足于分别讨论某个物理现象或某个哲学问题。他希望找到一种**能够跨学科理解事物的共同语言**。例如，他的系统主义强调，研究一个事物，不能只看它本身，还要看它由什么组成、处在什么环境、与其他事物有什么关系，以及哪些机制使它保持或改变状态。

我最近搜索和我的研究体系相似的工作，发现并开始了解邦格，发现了一个值得比较的问题：**两条从哲学性疑问出发的研究路径，为什么后来都逐渐走向系统、机制与研究方法？** 这篇短文记录的，就是这种相似性及其界限。

<a id="bunge-systematic-philosophy"></a>

## 邦格：从哲学疑问走向系统哲学

邦格在回忆和访谈中说，他在中学时期就对哲学产生了浓厚兴趣。20世纪30年代，天体物理学家爱丁顿（Arthur Eddington）和金斯（James Jeans）对宇宙和物理学的哲学解释使他着迷，也让他产生怀疑。为了判断这些说法是否站得住，他选择认真学习物理学，而不是只在哲学层面争论。

此后，他长期研究物理学基础、因果性和科学方法。1966年前后，他开始构思更系统的语义学与本体论研究；1972年进一步形成完整哲学著作的计划。1974年至1989年出版的八卷本《基础哲学论》（*Treatise on Basic Philosophy*），把语言与意义、世界的构成、知识与方法、科学和伦理放进一个相互关联的体系。

他的系统主义（Systemism）强调：理解事物，不能只看孤立的部分或抽象的整体，还需要研究组成、环境、结构以及产生变化的机制。

值得注意的是，**邦格不是先拥有一套完整的世界理论，再把事实填进去**。从早期疑问到成熟体系，中间经历了数十年的专业研究和反复修正。

<a id="language-and-concepts"></a>

## 更早的一条线索：我曾花一年研究中文和语言学

回顾自己的经历，我发现研究的起点不能只从2025年的宇宙哲学谈起。大约在2024—2025年前后，我曾花整整一年研究语言学（包括中文和英文，以及它们的对比研究）。我关注的不只是语言怎样表达，更包括文字、语义和概念这些问题。这段经历比后来关于宇宙、生命和复杂系统的系统整理早得多。

后来我又写了专门讨论文字、语言和概念的文章。它们并不是凭空出现的兴趣，而与之前的语言学思考有联系。等到研究进一步发展为 CF Grammar 和 Representation 时，我所关注的仍有一个贯穿始终的问题：**我们用什么符号和概念描述世界？这些概念究竟指向什么？它们有没有把现实中的关键区别表达出来？**

邦格把语义学放在八卷本《基础哲学论》的开头，提示了一个重要次序：在讨论世界由什么组成、为什么变化之前，我们需要认真检查**语言、概念与现实之间的关系**。如果概念含混，后面即使推理得很严密，也可能是在讨论一个未被正确表示的对象。

当然，两段研究不能混为一谈。我早年研究的是中文和语言学；邦格的系统语义学更集中于科学概念、指称、解释与真理。两者的对象和技术内容不同，**相似的是对“我们怎样用概念理解世界”的长期关切**。而且，目前只能说这些早年兴趣与后来研究存在连续性，不能把整个研究历程写成事先安排好的必然发展。

<a id="cosmic-questions-to-representation"></a>

## 我的路径：从宇宙、生命与信息，走向 Representation

回看自己的研究，起点也带有很强的哲学性质。

2025年，我写下关于宇宙哲学的第一版，试图思考一个宽泛的问题：为什么一个看似无序的世界，能够出现秩序、生命、认知和文明？这是一份哲学性的开放研究议程，而不是已经得到物理学验证的理论。

2026年7月至8月，我继续追问：结构是怎样形成并留存的？不同领域看起来完全不一样的现象，背后是否有共同的生成机制？研究也逐渐发现，不能简单把“宇宙趋向越来越复杂”当成结论。一个更具体的问题浮现出来：**系统能否保存过去的信息，并用它改变未来可以到达的状态？**

到了9月，研究的重心又改变了。我越来越关心的，不只是某个现象该怎样解释，而是：**我们一开始有没有把问题表示正确？** 一个事物处于什么状态？它与环境如何相互作用？哪些约束限制了它？在特定目标和时间范围内，它还保留哪些可行路径？

CF Grammar 由此逐渐形成。随后，Generator、Viability、Evidence Updating 等概念和方法被放进同一研究工作流，并用于企业、经济、飞行、学习和其他具体问题。这里的 Viability Theory 并非新近发现，而是已经被持续引用和吸收的重要理论来源。

<a id="comparison-and-limits"></a>

## 两条路径的相似与不同

把两条研究路径并列，可以看到一种共同的推进方式：

**哲学性的整体问题 → 具体科学与现实的检验 → 寻找跨领域的共同机制 → 建立较稳定的概念与研究方法 → 再回到现实检验。**

但区别同样重要。

邦格的工作是经过长期物理学、数学和科学哲学训练，发展出相当完整的哲学与本体论体系。他的 CESM 表示法，也已有后续研究者发展成实际建模指南。

我的研究目前更侧重于**跨领域研究时应该怎样正确表示问题、识别状态和约束、推断未来路径，以及在证据不符时修正甚至重建表示**。它不试图替代每门学科的专业模型，而是希望形成一种可以实际执行的共同研究语言。AI 的参与又带来一个新的实践目标：让普通人也有机会借助流程和工具，减少原本需要丰富经验才能识别的推理错误。

这些方向有交集，但**研究路径相似，不等于理论内容相同，更不等于成熟度和有效性相当**。尤其是，我们提出的流程是否真的改善判断，仍需要与现有方法进行对照检验。

<a id="revisable-method"></a>

## 从“解释整个世界”到“学习怎样研究世界”

最初，我们可能想回答一个极大的问题：世界为什么会形成今天这个样子？

<a id="what-the-method-seeks"></a>

但研究深入以后，也许会发现一个更基础、也更实用的问题：**面对世界上不断变化的事物，我们应该怎样提出问题、建立表示、寻找机制、理解未来的可能性，并且知道自己什么时候理解错了？**

从这个意义上说，研究的成果不一定是一个包罗万象的最终答案。它也可能是一种更可靠的认识方式。

**哲学问题提供方向，现实和科学提供约束；真正有生命力的研究方法，必须允许它自己被修正。**
