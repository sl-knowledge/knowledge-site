# 存在即区别：存在、区别、关系与意义

**To Be Is to Be Distinct: Existence, Distinction, Relation and Meaning**

_宇宙觉醒 · 哲学基本问题 · 第 0.01 篇_

> **本文的论点：** 存在即区别（To be is to be distinct）。一个东西存在，当且仅当有别的东西与它有区别；区别本身是一个成立的关系。关系是由存在的项组成的对的一类。一个东西的意义，由它在哪些成立的关系的哪些对中出现来给出。由这些定义可以推出：一个东西存在，当且仅当它的意义不是空的。本文只用两个不定义的本体论词：**区别**与**成立**。其余每个词，都只用逻辑词、集合论词，以及在它之前定义过的词来定义。

---

## 一、问题：一个体系从哪里开始（Where a System Begins）

任何体系都必须有一个起点，而起点本身不能再由体系内部的更基本的东西来证明。所以，选择起点的标准只能是另外几条：

1. **尽可能少。** 不定义的词越少，后面的一切越能被检查。
2. **尽可能精确。** 能够判断一个情形属不属于它。
3. **能排除东西。** 一个什么都不排除的起点，什么也没有说。
4. **能推出东西。** 由它出发，能得到不平凡的结论。

这几条大致对应 Carnap 为概念的“解释”提出的标准：相似、精确、有成果、简单（《概率的逻辑基础》，1950）。

**本文的写法规则：** 每个定义中出现的每个词，只能是下面三类之一：

1. 不定义的词；
2. 在它之前已经定义过的词；
3. 定义中正在引入的变量（x、y、R 等）。

**不定义的词（undefined terms）分三类：**

| 类别 | 词 | 说明 |
|---|---|---|
| 逻辑词（logical terms） | 不、和、或、如果……那么、当且仅当、所有、有、同一 | 一切严格写作共用的工具，不作任何本体论断言 |
| 集合论词（set-theoretic terms） | 类（class）、属于（membership） | 同上。“项”“对”“前项”“后项”不另设，都由这两个词定义 |
| 本体论词（ontological terms） | **区别**（distinction）、**成立**（obtains） | 本文真正的起点。体系对世界的断言，从这两个词开始 |

**项（item）。** 项是能属于某个类的类。（即通常所说的“一组”或“集”。）

> 用到的词：类、属于。

为什么要区分“类”与“项”：有些类太大，不能属于任何类，例如“所有项组成的类”。如果把它也当作一个项，就会出现“所有集合的集合”那一类悖论。所以本文的变量 x、y 都只取项；类可以被谈论，但不一定是项。（这一写法在研究中发现：von Neumann 1925、Gödel 1940 的类—集合论。）

**所用的形式体系。** 本文使用这种类—集合论，并包括基础公理（没有项属于它自己）。陈述中可以对类作量化（例如“有一个关系 R”），但不把类收集成更大的类。“区别”是项之间的原始谓词，“成立”是作用于类的原始谓词。

**定义的顺序：**

项 → 区别（规则一、二）→ 存在（规则三；公理一：非空）→ 对 → 前项、后项 → 关系 → 成立（公理二：区别关系成立）→ 位置 → 意义

正文各节按这个顺序排列：第二节区别，第三节存在，第四节关系，第五节意义。

## 二、区别（Distinction）

**刻画：** x 与 y 有区别：x 实在地不是 y（x、y 都是项）。

**地位：** 不定义的本体论词，是本文的哲学起点。

**区别与不同一（distinction and non-identity）。** 区别蕴含不同一，但不必等于不同一：

- **规则一（蕴含不同一）：** 如果 x 与 y 有区别，那么 x 不是 y。
- 反过来不能必然推出：两个项不同一，不一定有区别。
- **规则二（对称）：** 如果 x 与 y 有区别，那么 y 与 x 有区别。
- **规则三（存在者两两有区别）：** 如果 x 与 y 都存在，并且 x 不是 y，那么 x 与 y 有区别。（“存在”在第三节定义；这条规则在那里之后才生效。）

为什么需要对称：如果只有 a 与 b 有区别，而 b 与 a 没有区别，那么按第三节的定义，a 存在而 b 不存在；可区别关系又包含 (a, b)，而关系只能由存在的项组成，区别本身就不再是一个关系了。

为什么需要规则三：没有它，可以有这样的情形：a 与 b 有区别，c 与 d 有区别，四者都存在，但 a 与 c 不同一却没有区别。这与下面第 3 点的主张（两个存在的东西只要是两个，就有区别）不符。规则三不会让数学对象自动存在，因为它的前提已经要求两者都存在。

三条规则合起来是说：**在存在者之间，区别与不同一完全重合；区别多出来的内容，只在于哪些项存在。**

**推论（第三节定义存在之后可证）：x 与 y 有区别，当且仅当 x 与 y 都存在，并且 x 不是 y。**
- 正向：有区别就不同一（规则一）；由对称（规则二），x 与 y 各自都与某个项有区别，所以都存在。
- 反向：即规则三。

这个推论说明，在本体系内，“区别”与“存在”可以互相定义：先给出区别，就确定了哪些项存在；先给出哪些项存在，区别就是它们之间的不同一。这正是“可互换”的形式内容（第三节）：两者不是一个化归为另一个，而是同一个事实的两种说法。

需要说清两点：
1. 这个体系**没有**说明为什么有存在者、为什么是这些存在者。它只说明，“有存在者”与“有区别”是同一件事。“为什么有而不是无”仍是哲学的核心问题之一，不由定义回答。
2. 一个项不同一于另一个项，却不存在，这种情况本体系**允许**，但不**要求**。本文的主张只是：哪些项存在，不能由集合论自动判定。

世界的具体结构（哪些项之间有哪些关系）不由“区别”给出，而由其他成立的关系给出（第四节）。

为什么必须这样：如果区别就等于不同一，那么“有 y 与 x 有区别”对任何项都成立（任何集合都能找到另一个与它不同的集合），存在就退化成“是一个项”，数学对象会被集合论自动判定为存在。不同一是形式工具中的关系；区别是世界中的关系。集合论是谈论存在者的工具，不是存在者的清单。

本文的实质内容在两个主张：

- 存在与区别可以互换（第三节）；
- 区别是世界中成立的关系，而不只是能被写出的关系（第四节，公理二）。

**四点说明：**

1. **区别不需要谁去区分。** 任何去区分的东西，本身必须先与它所区分的东西不同，否则它什么也区分不了。所以区别先于任何区分者（倒退论证）。并且，在出现任何认识者之前，物质宇宙已经有一百多亿年充满区别的历史（时间论证）。
2. **要把区别与区分分开。** 区别属于存在本身；**区分**（distinguishing）是某些结构对区别作出的表示：眼睛分辨颜色，仪器读出数值，思想分清概念。概念上的模糊、划分的任意，都属于区分，不影响区别本身。
3. **区别不要求性质上的不同（numerical distinctness）。** 两个存在的东西只要是两个，就有区别（规则三），不要求它们在某种性质上不同。Black（1952）设想的两个完全相同的铁球，是两个，所以有区别。但反过来，形式上的两个项（例如两个集合）不同一，并不因此就有区别；它们是否存在，本文不预先决定。
4. **区别只要求“至少二”。** 它不预设世界是离散的，也不预设清晰的边界，更不预设世界恰好由两种基本状态构成。

**为什么是“二”（why two）。** 不是因为世界由两种材料构成，而是因为区别有两端：x 不是 y。阴之所以为阴，只是相对于阳。“二”是区别的两端，不是实体的种数。

## 三、存在（Existence）

**定义（论题）：** x 存在，当且仅当 x 是一个项，并且有一个项 y，x 与 y 有区别。

> 用到的词：项、有、区别。

**地位：** 这是一个实质的本体论论题，不是逻辑定理。在普通的一阶逻辑中，只有一个项的论域是允许的；本论题主张，这样孤立的项不存在。

**“全体”不是一个存在者。** 所有存在的项组成一个类，记作 S。分两种情形：

- 如果 S 太大，不是项，那么按定义它不是存在者，因为只有项才可能存在。
- 如果 S 是项，那么假如 S 存在，S 就必须属于它自己（它包含所有存在的项）；而集合论的基础公理不允许任何项属于它自己。所以 S 不存在。

两种情形下，S 都不是存在者。说“所有的区别”“所有存在的项”，是复数的说法，不指另外一个存在的“全体”。这一点由定义与集合论的基础公理得出，不需要另外主张。

**公理一（非空）：至少有一对项彼此有区别。**

没有这条公理，“没有任何存在者”的情形也满足所有定义与规则，下面第五节的定理虽然成立，却是空真。这条公理断言世界中至少有存在者，因而至少有两个。它的根据是事实，而不是定义：写下这句话的人和这句话，就已经是两个有区别的东西。

**可互换（convertibility）。** 本文不是把存在化归为一个更基本的东西，而是说：是一个存在者，与和别的东西有区别，是同一个事实的两种说法。中世纪哲学“存在与一可以互换”的学说，正是这种结构。

**排除：**

- **单纯的一（the simple One）。** 一个完全没有内部区别、外面又没有别的东西可与之不同的“一”，没有任何东西与它有区别，所以不存在。
- **没有任何区别的赤裸实体（bare substratum）。** 传统实体论中，去掉一切性质后剩下的“纯基质”，不存在。
- **作为一个存在者的“全体”（the whole as an existent）。** 见上文的两种情形，不存在。

## 四、关系（Relation）

关系的定义需要先定义“对”。下面三个定义只用到“类”“项”与“属于”。

**对（pair）。** x 与 y 的对，记作 (x, y)，是这样一个项：它的成员恰好是 {x} 与 {x, y}，两者可以相同。这里 {x} 是只有 x 属于的项，{x, y} 是只有 x 与 y 属于的项。（Kuratowski，1921）

> 用到的词：项、属于、只有、和。

**前项（first term）。** 一对的前项，是属于这一对的所有成员的那个项。

> 用到的词：对、属于、所有。

**后项（second term）。** 一对的后项，是这样一个项 y：这一对的成员恰好是 {前项} 与 {前项, y}。

> 用到的词：对、前项、项、属于、只有。

这样，当 x 与 y 不同一时，(x, y) 与 (y, x) 是不同的两个项，“次序”由构造本身给出，不需要另外定义。当 x 与 y 同一时，后项就是前项，定义仍然成立。这一情形必须保留：自身与自身的关系，以后讨论自我认识时会用到。

**关系（relation）。** 关系是由存在的项组成的对的一类。

> 用到的词：类、对、存在（第三节）。

说明：

- 本文的关系都是二元关系（binary relation）。
- 关系是一个类，不一定是项。小的关系是项，可以再作为别的关系的一端；太大的关系只是类。
- **区别本身是一个关系：** 由所有彼此有区别的项组成的对，所构成的那一类。

**成立（obtains）。** 不定义的本体论词，用于整个关系：一个关系成立，是说它是世界中实际有的关系，而不只是能被写出来的关系。

**规则：成立不必传给子类。** 一个关系成立，不能保证它的每一部分都成立；某些部分可以成立，但这需要各自成立，不由整体成立推出。例如，区别关系成立；但如果由此推出它的每一个子类也都成立，那么任何由不同的项拼凑成的对的一类，都会“成立”，“成立”就失去了内容。

为什么“成立”不能定义为“这一对属于这个关系”：因为那只是类的成员关系，任何拼凑出来的一类对都满足它。这正是纽曼难题的要害（第九节反驳三）。

**公理二：区别关系成立（the distinction relation obtains）。** 这是存在即区别这一论题在关系层面的内容：区别不只是能被写出，而是世界中实际有的。由第二节的对称规则，区别关系中的每一对，两端都存在，所以区别关系符合关系的定义。

**位置（position）。** x 在关系 R 中的位置，是 R 中 x 作为前项或后项出现的那些对所组成的类。

> 用到的词：前项、后项、对、属于、关系、类。

这里的位置是**具体的**位置：记录 x 出现在哪些对中、处在哪一端，而不是 x 所扮演的抽象结构角色。

**关系项不先于关系（relata do not precede relations）。** 此与彼不是先作为独立的东西存在，再由关系把它们连起来。按第三节，是一个存在的项，与处在区别关系的一端，是同一个事实。

**被描述的关系与成立的关系（described vs. obtaining）。** 一部小说描述了独角兽：小说存在，它所作的描述存在（这是一种区分，属于表示），独角兽却不存在。被描述的关系，不因被描述而成立。

**可能（possibility）。** 未实现的可能不在任何成立的关系之中，所以不是存在者。关于“可能”的陈述（例如“这块石头可能碎”）说的是什么，需要先讨论规律与可行性，留待专门一篇。

## 五、意义（Meaning）

**定义：** 对任意关系 R 与任意对 p，**R 与 p 构成 x 的一个意义条件**，当且仅当 R 成立，p 属于 R，并且 x 是 p 的前项或后项。x 的意义，就是 x 的所有意义条件。

> 用到的词：关系、对、成立、属于、前项、后项、所有。

形式上，这是一个三元条件 M(x; R, p)，不是一个对。不能写成 (R, p)，因为 R 可能是真类，而对只能由项组成。

**为什么不写成“所有位置组成的类”。** x 在一个大的关系中的位置本身可能是真类，而真类不能再作为成员被收集进另一个类。所以意义不定义为一个汇集，而定义为一个条件：只说什么样的 R 与 p 构成 x 的意义条件，既不把它们包装成对，也不把它们收成一个更大的类。x 在某一个关系 R 中的位置，仍是 R 的子类，可以合法地写出（第四节）。

**定理：x 存在，当且仅当 x 的意义不是空的。**

“x 的意义不是空的”，即：有某个 R 与某个 p，构成 x 的一个意义条件。

- **正向。** x 存在，所以有 y 与 x 有区别；由对称规则，y 也存在，所以 (x, y) 属于区别关系。又因为区别关系成立（第四节，公理二），区别关系与 (x, y) 构成 x 的一个意义条件，所以不是空的。
- **反向。** 有成立的 R 与属于 R 的 p，x 是 p 的前项或后项。关系只由存在的项组成，所以 x 存在。

**地位：** 由定义、区别的规则一与规则二、公理二推出的定理。公理一保证它不是空真。它的实质内容来自存在论题，不是另一个独立的发现。

**形式定理与哲学命题（formal theorem and philosophical claim）。** 这条定理是本文形式语言中的定理，由定义、规则与公理保证。它对现实与意义有所断言，只能来自两处：

1. **论题本身。** “存在即区别”与“区别关系成立”是实质的主张，可能是错的。如果它们错了，定理在形式上仍然成立，却不再描述世界。
2. **解释的恰当性（adequacy of explication）。** 本文的“意义”是对日常“意义”一词的解释（Carnap 意义上的 explication），不是对它的报告。它是否恰当，要按 Carnap 的四条标准判断：与原词相似（见下文“意义的层次”与语言层次上的旁证）、精确、有成果、简单。如果这个解释不恰当，定理说的就只是本文所定义的“意义”，而不是人们通常所说的意义。

所以，这条定理的哲学分量，等于两个论题的可信度，加上这个解释的恰当程度。三者都要单独论证，不能由定理本身代替。

**这为什么不是循环。** 循环是用甲证明乙，用乙证明丙，再用丙证明甲。这里有一条单向的定义链（第一节），定理由它推出。存在、区别、意义三个词外延相同、意思不同：

| 词 | 从哪里看 | 问的是 |
|---|---|---|
| 存在 | 从“有什么”看 | 有没有 |
| 区别 | 从两端之间看 | x 是否不是 y |
| 意义 | 从其中一端看 | 这一端处在哪些成立的关系的哪些位置 |

阿奎那《论真理》第一问第一条所说的超越属性也是这样：存在、一、真、善，外延相同，意思不同。本文不把“善”放入其中，以免把价值带进本体论。

**意义的层次：同一个定义，不同种类的成立的关系。**

| 层次 | 意义 = 在什么关系中的位置 |
|---|---|
| 最基本的 | 在物理上成立的关系中的位置。比如岩石成为生命的环境 |
| 亲身经历的好坏 | 一个事件与一个有感受的生命能否继续存在之间的关系 |
| 语言的意义 | 一个符号与其他符号、与世界之间的关系 |
| 人追问与赋予的意义 | 一个人的当下，与他的过去、未来、他人和所做之事之间的关系 |

日常所说的“意义”多指较高的层次。它们需要特定的结构才会出现，但按本文的定义，与最基本的意义是同一种东西。

**意义的丰富程度（richness of meaning）。** 意义有多少之分：一个东西所处的成立的关系越多，它的意义越丰富。怎样比较“多少”与“深浅”，需要“依存”“凝聚”等后续概念，留待后续各篇。

**语言层次上的旁证。** Saussure 说，语言中只有差异，一个符号的价值由它与其他符号的关系决定（1916）；Firth 说，看一个词与哪些词相伴，就知道它的意思（1957）；维特根斯坦说，一个词的意义就是它在语言中的用法（《哲学研究》§43）。

今天的大型语言模型只从词与词的关系中学习，却在相当程度上表现出对意义的把握。但这一点有争议：Bender 与 Koller（2020）认为，只从形式中学习，学不到意义，因为意义还包括符号与世界的关系。按本文的定义，这场争论正是“哪些关系算进意义”的争论。所以这里只把它作为旁证，不作为证明。

**数学上的对应（correspondence, not proof）。** 范畴论的 Yoneda 引理说：在同构的意义上，一个对象由它与所有对象之间的态射完全确定。这与“一个东西的意义就是它的关系”形式相似，但它是范畴论内部的定理，本文只把它作为一个对应。

**相容性：一个模型（consistency: a model）。** 取两个项 a = ∅，b = {∅}；规定只有它们彼此有区别，即区别关系为 {(a, b), (b, a)}，并规定它成立，其他关系暂不规定为成立。于是 a、b 都存在，意义都不是空的；其他集合仍是形式上的项，但不存在，意义为空。三条规则、两条公理与核心定理都满足。这说明这套定义至少有一个相容的解释；它不是对现实本体论的证明。

| 2 | 存在 | x 是项，并且有项 y 与 x 有区别 | 论题 |

| 3 | 对、前项、后项 | 成员为 {x} 与 {x, y} 的项，及其两端 | 定义（集合论） |
| 4 | 关系 | 由存在的项组成的对的一类 | 定义 |

## 七、它排除了什么：难例检验（Hard Cases）

一个有内容的论题，必须可能被反例推翻：如果找到一个“存在、却不在任何成立的关系中”的东西，或者“在成立的关系中、却不存在”的东西，本文就错了。

| 难例 | 结果 |
|---|---|
| 单纯的一 | 没有东西与它有区别 → 不存在 |
| 全体（所有存在的项） | 不是项，或是项却不能属于自己 → 不是存在者 |
| 未实现的可能 | 不在任何成立的关系中 → 不存在 |
| 视界之外、永远到达不了我们的宇宙区域 | 与它自身的各部分有区别，处在成立的关系中 → 存在，有意义 |
| 小说中的人物 | 描述存在（属于表示）；人物本身不在成立的关系中 → 不存在 |
| 过去 | **待定。** 取决于“过去是否仍然成立”的决定（生长的区块，尚未作出） |
| 数与空集 | **待定。** 取决于“数学对象的地位”的决定（尚未作出） |
| **意识的感受**（被认为存在，却对物理世界毫无作用） | **真正的难例。** 按本文，要么它处在成立的关系中（例如与主体自身的状态），所以存在；要么它不存在。这是心灵哲学中的立场之争，留待专门一篇 |

## 八、它推出了什么（Consequences）

1. **在一定条件下，自我认识不能完整。** Lawvere（1969）的不动点定理说：在满足其条件的系统中（粗略地说，系统能把关于自身的每一个性质，都表示为它自身某个部分上的函数，即“逐点满射”），只要性质的取值范围 B 上有一个没有不动点的自映射，系统就不能在自身之内完整地表示关于自身的全部性质。而 B 只要至少有两个不同的元素，就有这样的自映射：取 a 不是 b，把 a 映到 b，把其余一切映到 a，这个映射没有不动点。
   - 本文提供的，是“至少有两个彼此有区别的存在者”。
   - 但这不自动意味着某个具体认识系统的取值范围 B 至少有两个元素。两者之间的对应，需要对每个系统单独说明。
   - 一个具体的认识系统是否满足定理的其余条件，需要逐个论证，见本系列论文一。
   - 所以这里的结论是条件性的：**凡满足这些条件的认识系统，都不能完整地认识自身。** 它不是“一切认识都不完整”的无条件定理。
2. **不需要可能世界作为存在者。** 可能不是存在者；关于可能的陈述如何为真，留待讨论规律与可行性的一篇。
3. **意义有了一个统一的定义。** 从岩石到人，意义是同一种东西，只是关系的种类与多少不同。

## 九、反驳与回应（Objections and Replies）

每条先分类：

- **H0：** 概念不同，澄清即可；
- **H2：** 评价标准或基本立场不同，原则上不会消失；
- **H3 / 技术问题：** 真正的批评，必须回答。

**反驳一：循环——“没有关系项，就没有关系”。**（H0 → 余下部分属 H2）
区别预设了此与彼的存在，所以用区别定义存在是循环的。这是对结构实在论最有名的批评（Psillos、Chakravartty）。
回应：本文的定义链是单向的（第一节）；存在论题是可互换论题，不是化归。是一个存在者，与处在区别的一端，是同一个事实。余下的分歧，是“起点是否必须由更基本的东西化归而来”，属于评价标准的不同。

**反驳二：布拉德雷倒退。**（技术问题）
若关系 R 连接 a 与 b，还需要另一个关系把 R 与 a、b 连起来，以至无穷（Bradley，1893）。
回应：倒退只在关系项先于关系、需要被“粘合”时才发生。本文的关系项就是关系的两端，没有缝隙需要粘合。

**反驳三：纽曼难题——结构是空话。**（技术问题，最强）
任何一个元素足够多的集合，都可以被赋予任何关系结构，所以“世界有某某结构”只说出了元素的数目（Newman，1928）。
回应：这个难题成立的前提，是“一切可以写出的关系都算世界的结构”。本文把“成立”作为不定义的本体论词，并且规定它不必传给子类：能写出的关系很多，成立的只是其中一部分。这与 Lewis（1983）的“自然性”、Sider（2011）的“结构”属于同一类回应方案（在研究中发现）。这是一个**回应方案**，不是完整的解决：本文只说有些关系成立、有些不成立，没有说明是哪些。
**让步：** 本文没有给出判别“哪些关系成立”的标准；这是认识上的问题，不是定义上的问题，留待后续。

**反驳四：存在不是谓词。**（H0）
康德说存在不是实在的谓词（《纯粹理性批判》A598/B626）。
回应：本文不是给概念加上一个性质，而是给出存在者的条件。Quine 的“没有同一性，就没有实体”，正支持这种条件。

**反驳五：区别是心灵划出来的。**（H2）
我们知道的区别都是我们划出的。
回应：倒退论证与时间论证（第二节）。
**让步：** 区别独立于心灵，是立场，不能从内部证明。如果认识者满足第八节第 1 点的条件，这与那里的结论一致：内部的表示，不能完整地说明整体。

**反驳六：区别就是“不同一”，没有说出新东西。**（H0）
回应：区别不等于不同一（第二节）。不同一是形式工具中的关系，任何两个不同的集合都满足它；区别是世界中的关系，不同一只是它的必要条件。如果把两者等同，存在就退化成“是一个项”。本文的内容在于：存在与区别可以互换；区别关系成立。

**反驳七：太平凡，什么也没说。**（H2）
回应：它排除了单纯的一、未实现的可能、赤裸的实体、作为存在者的全体；在一定条件下，它推出自我认识不能完整。能排除、能推出，就不空。

**反驳八：意义是语义的，不是本体的。**（H0）
意义属于语言与心灵，说石头“有意义”是滥用。
回应：本文的最基本意义与语言的意义是同一个定义的不同层次（第五节），语言的意义正是从符号的关系中来的。

## 十、在研究中发现的前人（Predecessors Found in Our Research）

这四个概念之间的每一条连接，前人都已经碰到过：

- **存在与相异：** 柏拉图《智者篇》把“相异”列为贯通一切的最大的种之一，并把存在的标志规定为能够作用或被作用（247e）；斯宾诺莎：“一切规定都是否定”；黑格尔《逻辑学》。
- **存在与差异：** 德勒兹《差异与重复》（1968）：差异就是存在本身，同一性是差异的结果。
- **关系先于对象：** Poincaré（1902）：数学研究的不是对象，而是关系；Cassirer（1910）：从实体概念到关系概念；本体结构实在论（Ladyman 与 Ross，2007）；Floridi（2008）：差异关系构成一切关系项；Barad（2007）：关系项不先于关系。
- **存在与意义：** Gabriel（2015）：存在就是出现在某个意义场中；Nancy（1996）：存在就是意义，存在总是“共在”。
- **区别与意义：** Luhmann 的系统论以 Spencer-Brown 的区别为起点，把意义规定为实际与潜在的区别；Bateson：造成差异的差异，是信息与心灵的单位。
- **意义与关系：** Saussure、Firth、维特根斯坦。
- **存在的可互换：** 中世纪的超越属性学说。
- **成立的关系与任意的关系：** Lewis（1983）、Sider（2011）。

**本文与他们的不同：**

1. **只承认成立的关系。** 德勒兹认为实在包括潜在，Luhmann 的意义依赖潜在；本文只承认成立的关系。
2. **区别不依赖观察者。** Spencer-Brown 与 Luhmann 的区别由观察者划出，Bateson 把区别限于心灵与信息的世界，Barad 依赖“能动的切割”；本文的区别先于任何区分者，属于一切存在。
3. **“全体”不是一个存在者。** Gabriel 主张“世界不存在”；本文的结论相近，但它由定义与集合论的基础公理得出（第三节）。
4. **定义链可以逐词检查。** 两个不定义的本体论词，加上逻辑词与两个集合论词（类、属于），其余逐一定义。
5. **与定理相接。** 区别为 Lawvere 的不动点定理提供“至少两个值”这一条件（其余条件需另证）；意义与 Yoneda 引理形式相应。

**为什么采用这种表示（why adopt this account）。** 与几种常见的存在标准相比，本文的方案有以下特点。完整的比较论证，留待面向期刊的修订稿。

| 方案 | 存在的标准 | 与本文的差别 |
|---|---|---|
| Quine | 一个理论的本体论承诺，看它的约束变量必须取哪些值 | Quine 由理论中约束变量的取值判断本体论承诺，并把“接受哪个理论”留给另外的考虑；本文则另外引入“区别”，明确区分形式上可以谈论的项与本体论上承认的存在者 |
| Meinong | 不存在的对象也“有”某种地位 | 本文不承认不存在的对象，未实现的可能与虚构人物都不存在 |
| 柏拉图《智者篇》 | 能够作用或被作用 | 需要先定义“作用”，本文在地基层不使用 |
| Gabriel | 出现在某个意义场中 | 本文的“意义”不依赖场与视角，而是成立的关系中的位置 |

本文方案的优点在于：
- 定义链单向，可以逐词检查；
- 能明确排除一些东西：单纯的一、未实现的可能、赤裸实体、作为存在者的全体；
- 存在与意义由同一条定义链给出。

本文方案的代价在于：
- 需要两个不定义的本体论词；
- 不回答哪些关系成立，也不回答为什么有存在者。

## 十一、尚未解决的问题（Open Problems）

1. **怎样认识哪些关系成立**（纽曼难题的认识部分）。
2. **意义丰富程度的比较**：需要依存、凝聚等后续概念。
3. **意识的感受**作为难例。
4. **过去与数学对象的地位**：取决于尚未作出的两个决定。
5. **关于“可能”的陈述如何为真**：需要规律与可行性的专门讨论。

_v0.3（2026-11-17）：按逐词检查重写定义链。_

- _不定义的词分为逻辑词、集合论词、本体论词三类；本体论词为“区别”与“成立”两个（用户确认）。_
- _删去未定义的“最小的关系”“区别的组织”“全部实际关系”“全体”。_
- _“对”“前项”“后项”用 Kuratowski 构造定义，包括 x 与 y 同一的情形。_
- _“成立”作为不定义的词，用于整个关系，不传给子集。_
- _存在论题加入“区别关系成立”，并写出存在与意义等价的正反两向证明。_
- _依存、约束移到后续各篇；“可能”的分析留待后续。_
- _难例中的“过去”“数”改为待定。_
- _大型语言模型改为旁证，并加入 Bender 与 Koller（2020）。_
- _Yoneda 引理改为“对应”。_
- _前人中增加 Floridi、Gabriel、Nancy、Lewis、Sider。_

_v0.4（2026-11-17）：改用类与项的区分。集合论词改为“类”“属于”，“项”由它们定义；变量只取项；关系、位置、意义都是类；“成立不传给子集”改为“子类”。由此直接得出：所有存在的项组成的类不是项，所以“全体”不是存在者（第四节，并加入难例）。对的措辞改为“成员恰好是 {x} 与 {x, y}，两者可以相同”。参考文献增加 von Neumann（1925）、Gödel（1940）。_

_v0.5（2026-11-17）：两处修正（用户确认）。一、区别蕴含不同一，但不等于不同一；否则存在退化为“是一个项”，数学对象会被集合论自动判定为存在。第二节、反驳六、术语表随之改写；“全体不是存在者”改为分两种情形论证，用到集合论的基础公理。二、意义改为条件定义：x 的意义包含 (R, p)，当且仅当 R 成立、p 属于 R、x 是 p 的一端；不再把可能是真类的位置收集成一个类。定理的证明随之改写。_

_v0.6（2026-11-17）：三处修正。一、区别增加对称规则，否则区别本身不符合关系的定义。二、意义改为三元条件 M(x; R, p)，不再写成 (R, p)，因为 R 可能是真类。三、按“每个定义只用前面的词”的规则，把存在一节移到关系之前（第三节存在，第四节关系）；“区别关系成立”从存在论题中分出，在关系与成立之后列为公理；“被描述的关系”“可能”两段与“未实现的可能”的排除，随之移到第四节。_

_v0.7（2026-11-17）：一、增加规则三：两个存在者只要不同一，就有区别（正文原有此主张，但原有规则推不出）。二、增加公理一（非空）：至少有一对项有区别，使核心定理不是空真；原“区别关系成立”改称公理二。三、第一节写明所用形式体系：类—集合论，含基础公理；可对类量化，不把类收成更大的类；“区别”是项之间的原始谓词，“成立”是作用于类的原始谓词。_

_v0.8（2026-11-17）：说明性修正，定义结构不变。一、第二节增加推论：区别当且仅当两者都存在且不同一；说明区别与存在可以互相定义，这是“可互换”的形式内容；体系不说明为什么有存在者；“不同一而不存在”的项是允许而非要求。二、“区别不等于不同一”改为“不必等于”。三、“成立不传给子类”改为“不必传给子类”。四定义的基本结构到此定稿，不再修改。_

_v0.8 补（2026-11-17）：两处措辞：“反过来不成立”改为“反过来不能必然推出”；“(x, y) 与 (y, x) 是不同的两个项”加上“当 x 与 y 不同一时”。第五节末增加一个相容性模型（来自外部审查）。四个定义的形式审查到此通过。_

_v0.9（2026-11-17）：按发表前审查修改，四个定义不变。一、第五节增加“形式定理与哲学命题”：定理的哲学分量来自两个论题与解释的恰当性（Carnap）。二、第八节第 1 点改为条件性结论：本文只提供 Lawvere 定理所需的“至少两个值”，其余条件需另证；反驳五、反驳七、第十节第 5 点随之修改。三、纽曼难题的回应改称“回应方案，不是完整的解决”。四、第十节增加“为什么采用这种表示”，与 Quine、Meinong、柏拉图、Gabriel 的存在标准作对照。_
