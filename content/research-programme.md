> **研究总体纲领｜2026 年 11 月 6 日讨论整理**  
> 这份文档不是一套新的术语或操作清单，而是对现有研究——表示、约束与可行性、证据更新、人机联合认知及各领域实践——的共同出发点与目的的概括。

<a id="research-objects"></a>

## 一、我们究竟在研究什么？

**我们研究的是：世界上的事物处于什么状态，这些状态如何在环境、相互关系与约束之下形成、维持和改变，以及从当前状态出发，未来有哪些可能的演化路径。**

同时，我们也研究另一个同样根本的问题：**人怎样从有限观察中建立对世界的表示（Representation），利用它解释和预测变化，并在现实与预期不符时修正自己的认识，必要时重新定义问题本身。**

因此，整个研究有两个相互联系的对象：

1. **真实世界的动态过程**：事物如何存在、相互作用、发生状态转移；哪些未来可达、可持续，哪些会因约束而失去可行性。
2. **认识世界的动态过程**：研究者怎样观察、提出问题、选择表示、形成假设、作出预测、检验与修正模型。

我们并不试图用一套具体方程解释所有领域，而是寻找不同领域可以共用的**提问方式与建模语言**：透过不同表象，重建起作用的生成机制。

<a id="minimal-representation"></a>

## 二、研究世界的最小表示

**研究开始时，要明确究竟在研究什么问题、怎样表示这个问题，并让后续观察继续检验与修正这一表示。**

一个尽可能简单、又足以推进研究的起点，是下面六个问题：

| 核心维度 | 要问的问题 |
|---|---|
| **State（状态）** | 它现在处于什么状态？哪些可观察，哪些关键内部状态尚未知晓？ |
| **Environment（环境）** | 它处于什么外部条件中？环境正在如何变化？它能否反过来影响环境？ |
| **Relations（关系）** | 它与哪些其他事物相连？资源、信息、利益与作用如何传递？ |
| **Constraints（约束）** | 在特定目标和时间范围内，什么真正限制它的维持、行动或变化？ |
| **Capabilities / Mechanisms（能力与机制）** | 它能够完成什么任务？通过什么内部结构、规则和作用机制产生结果？ |
| **Dynamics / Paths（动态与路径）** | 从当前状态出发，它可能怎样变化？哪些路径可达、可持续、可恢复或可重构？ |

能力描述能够完成什么任务，机制解释结果怎样形成，两者需要区分。这些不是一张要求机械填写的清单。具体研究中只保留真正决定结果的变量与联系；某个约束解除后，还必须检查新的限制是否出现。

尤其要区分三件事：

- **现象不等于机制**：看到收入增长、花朵枯萎或一个人作出选择，不代表已经知道原因。
- **当下状态不等于未来能力**：两个系统今天的结果相似，内部能力、资源缓冲与未来可行路径可能完全不同。
- **可行不等于必然，也不等于值得追求**：我们要区分能够发生、较可能发生、能够维持，以及在特定价值目标下应不应该争取。

<a id="changing-possibilities"></a>

## 三、真正重要的是状态如何转移，以及未来可能性如何改变

静态描述只是一个时间截面。更值得研究的是：

**当前状态 → 环境与关系中的相互作用 → 关键约束与生成机制 → 未来状态及其可行路径。**

这不是固定的单向链条。系统可能改变环境，竞争者会回应，行动也会反过来改变系统的能力与约束，形成反馈。

因此，我们不能只问“它会变好还是变坏”，还要问：

- 它为何会沿某条路径变化？
- 途中有没有必须满足的生存与资源条件？
- 一个约束被解除后，新的瓶颈是什么？
- 当环境冲击到来时，它能否维持、恢复，或者重新组织自己？
- 某些行动是否能打开原先不可达的未来选择？

由此可以把我们的关注点进一步概括为：**研究一个系统的未来可能性，是怎样由当前状态、历史、环境、关系、能力与约束共同塑造，并不断变化的。**

这里的“可能性”不是抽象的乐观想象，而应落实到可观察的条件、明确的机制和可以被证伪的预期。

<a id="representation-and-revision"></a>

## 四、为什么“表示”是整个研究的起点？

人们面对一个问题时，常常急于解释、搜集数据或选择方案。但如果最初的研究对象、目标或变量就选错了，后面分析越详细，也可能离真实问题越远。

例如，研究一家企业，如果一开始只问“收入会不会增长”，可能忽略与投资者有关的问题：**销量、价格、成本、产能利用率、资本投入与融资负担如何共同改变普通股东未来获得的价值？**

同样，研究企业重构时，不能只问“转型成功了吗”。旧业务信用循环的修复，与新业务建立可持续增长机制，可能是两条不同路径，必须分别表示与验证。

所以研究中有两种不同的修正：

1. **Judgement Updating（判断更新）**：问题表示暂时适用，新证据使我们调整参数、概率或结论。
2. **Representation Updating（表示更新）**：原有问题没有抓住真正的对象、变量或生成机制，需要重新定义问题、拆分系统，甚至更换模型。

这两种修正可以同时发生：重建表示也会改变判断。记录修正、实际变化与机制修订的作用，需要分别说明。

**当预测与现实不符时，不能只拼命维护或微调原来的解释；要检查是不是一开始就问错了问题。** 当然，也不能每遇到反例就任意换故事。若据此主张新表示更有解释或预测价值，应提出可检验的差别或明确的改进标准。

<a id="research-purposes"></a>

## 五、为什么要这样研究？

我们这样研究，不是为了给世界上的每种事物贴标签，也不只是为了获得更复杂的解释。它至少有四个相互连接的目的。

### 1. 理解：知道事物为什么会是现在这样

我们希望从表面现象走向生成原因，理解历史、结构、环境与约束如何共同作用，减少凭直觉、标签和单个结果下判断的错误。

这种理解也提醒我们：**我们构造的模型不是世界本身**。知道什么尚未被证明，与知道什么已经发生，同样重要。

### 2. 预测：识别未来有哪些可能的路径

理解机制，是为了进一步判断在什么条件下会发生什么变化；不仅预测一个结果，还研究变化的路径、时间、风险和可持续性。

面对复杂系统，合理的输出往往不是一个确定的答案，而是若干条件明确、证据强弱不同、能够持续更新的路径判断。

### 3. 选择与行动：找到可以改变未来的条件

如果知道状态受哪些约束、通过什么机制变化，我们就有机会判断哪些行动可能有效：调整资源、改善环境、改变规则、建立新能力，或者保留关键缓冲。

**研究不只是为了在既有选择中选一个答案，也可能帮助我们创造原来不存在的可行选择。**

但是，模型本身不能替人决定“什么最值得追求”。企业的股东价值、系统的安全、人类的福祉和个人的生活目标，都需要分别明确。能改变不代表应该改变；行动也必须考虑代价和其他人的利益。

### 4. 理解有限：知道何时行动，何时接受

任何系统都受到条件限制。对人的研究也是如此：一个人的选择与行为，受到经历、能力、认知、欲望、资源和环境影响。

理解这些条件，不等于认同所有行为或取消责任，却可能帮助我们少一些简单苛责，多一些理解与悲悯。

因此，研究的实践结果可以有两个方向：**对可改变的事情，更有依据地行动；对暂时不可改变的事情，更清楚地理解其局限，减少无意义的执著。**

<a id="research-cycle"></a>

## 六、一个完整的认识与行动循环

```text
明确研究对象与目标
        ↓
建立表示（状态、环境、关系、约束、机制）
        ↓
重建生成原因与动态反馈
        ↓
推演可行路径，提出可检验的预测
        ↓
判断价值、选择行动或暂缓行动
        ↓
观察现实，根据证据更新判断
        ↓
必要时修正假设，或重建表示
        ↺
```

这个循环同时发生在两个层面：**外部世界在变化，我们对世界的认识也在变化。** 研究者并不站在系统之外获得全知视角；自己的观察、模型、行动和反馈本身也受到条件约束。

<a id="cross-domain-transfer"></a>

## 七、为什么它能够跨领域使用？

不同领域的具体规律并不相同，但我们提出的问题可以有共同结构：

| 领域 | 状态与动态研究的核心问题 |
|---|---|
| **企业与投资** | 企业经营能力与现金循环怎样变化？未来每股价值如何演化？市场价格和预期是否已反映这些变化？ |
| **宏观经济** | 生产、支付、需求、技术与制度的相互作用如何使经济持续运转、停滞或重构？ |
| **控制与安全** | 在资源、性能、环境与安全约束下，怎样使状态沿可行路径变化，并保留恢复机会？ |
| **生命** | 一个生命系统怎样维持自身、应对环境变化、成长或衰退？ |
| **学习与 AI** | 认知系统怎样从已有表示生成预测，通过反馈发现失配，并形成更好的理解与提问能力？ |
| **人与社会** | 人的行为与社会关系如何在历史、认知、利益和约束下形成？哪些条件使改变成为可能？ |

跨领域迁移的不是某个领域的现成答案，而是**提出问题、寻找机制、识别约束、检验预测和修正表示的能力**。

<a id="testable-method"></a>

## 八、为什么要把方法变成普通人也能使用的流程？

好的研究者往往经过多年实践，才逐渐形成识别关键变量、发现推理跳跃、主动寻找反证、知道何时不能下结论的能力。

我们的目标不是宣布这套方法超过了最优秀的专家，而是**尝试把其中一部分关键推理纪律显性化、程序化**，再借助 AI 的资料检索、整理、计算和比较能力，降低普通人进行高质量判断的门槛。

真正需要检验的是：与“普通人直接让 AI 给出答案”相比，按这一流程工作，能否更早发现错误的问题表示、减少证据越级推断、识别更关键的反证，并在新信息出现后更准确地修正判断。

这仍是一个需要对照实验和长期追踪来验证的研究目标，而不是已经被证明的效果。

<a id="summary"></a>

## 九、总体概括

**我们研究什么？**

> 世界上的事物并不是孤立、静止的对象，而是存在于环境与相互关系之中，不断发生状态变化的系统。我们希望理解它们的当前状态、生成机制、约束条件与未来可行路径；同时研究人如何建立、检验和修正对这些动态过程的认识。

**我们为什么研究？**

> 为了更准确地理解世界为什么如此，识别未来可能发生什么，发现哪些条件能够被改变、哪些新的选择可以被创造；也为了认识事物和人的有限性，在需要行动时更有依据，在无力改变时更加理解与坦然。

用最简短的话说：

**理解世界 → 认识可能 → 选择与行动 → 反馈修正 → 理解有限。**

这不是一条走完就结束的直线，而是一个不断循环、不断改进自身表示的研究过程。

---

这是一份跨领域研究的总纲性概括。相关概念与方法是否在某一领域带来优于现有方法的增量价值，仍应由明确的预测、对照与现实结果来检验。领域示例用于界定研究问题，不构成操作指引或投资与交易建议。
