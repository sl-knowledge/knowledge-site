本站用于保存和持续修订研究文档。这份计划记录接下来的整理方向，使理论、方法与应用之间的联系更清楚，也使检查与修订能够持续进行。

## 术语、符号与公式

- [ ] 以[《统一术语、符号与知识等级》](./framework/methods/canonical-vocabulary.md)为基础，逐篇核对概念的含义、适用条件与中英文名称。
- [ ] 区分同义表达与同名异义；同一符号在不同语境下使用时，明确局部定义与对应关系。
- [ ] 核对公式的假设、时间尺度和推导口径，保留必要的条件与知识等级说明。

## 理论、方法与应用之间的链接

- [ ] 为关键概念建立稳定入口，优先连接已有的定义章节。
- [ ] 在文章的重要使用位置补充链接，区分定义引用、方法应用与一般相关阅读。
- [ ] 逐步加入反向链接，显示哪些文章引用了当前页面；进一步评估是否需要逐个概念的引用清单。
- [ ] 区分概念与主题，按需要整理主题索引。

关键词链接与反向链接正在小范围试做。链接是否成立，要核对实际含义；词语相同，本身不足以证明概念相同。

## 中英文对应

- [ ] 持续检查两种版本的主张、假设、术语、公式和文章版本是否对应。
- [ ] 保持对应文章与概念入口之间的链接关系，减少翻译中的含义偏移。

## 检查与修订

- [ ] 逐篇检查内部链接、章节入口、公式与 Markdown 显示。
- [ ] 持续核对来源、论证与知识地位，明确已有结果、条件性推论、假说及未知之处。
- [ ] 对纠错与反例保留可追溯的修订记录，重要变更同步反映在[网站更新记录](./updates.md)中。

## 推进方式

先审阅小样本，再分批扩展。当前已有统一术语表、文章版本、中英文对应稿及分类目录，后续仍需结合具体内容逐项核对。

这份计划随研究和整理进展修订，不设固定完成日期。有关术语、链接和论证的问题，可以通过[研究反馈](https://github.com/sl-knowledge/knowledge-site-en/issues/new?template=research-feedback.yml)提出。
