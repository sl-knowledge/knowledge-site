这套研究围绕两个问题展开：怎样从开放世界证据中发现与目标、时域有关的表示；怎样发现表示失效，并通过必要的结构修订恢复适用性。

主线为：**现实 → 表示 → 推理与决策 → 反馈 → 修订**。下方先给出共用架构与三部主干，再列出系统、价值和专题探索。专题中的工作假说保留自己的验证要求。

<a id="scope"></a>

## 适用范围：这套框架研究什么

本站的研究有两个相互连接的层次：

- **系统怎样持续与调整。** 一个系统在必须满足的约束之内，还能维持多久、还有哪些路、调整来不来得及；对于具有选择能力的行动者，还要问自己的选择与承诺怎样改变这些条件。
- **我们怎样认识这些系统。** 怎样从不完整的证据中构造表示，比较竞争解释，形成可检验的预期，并在反馈出现后发现模型失效、修订理解。

第一层帮助分析持续、依赖与恢复窗口；第二层也适用于语言、学习和概念形成等研究，不要求对象同时面临存续危机。主体建模、网络科学、系统动力学等方法各有任务；本站的框架帮助组织问题，也需要借助相关领域的成熟方法完成具体建模与检验。

### 什么时候值得检查约束与恢复窗口

以下是值得检查的条件，不是必须同时满足的准入清单：

1. **有需要持续满足的约束。** 例如关键功能、履约条件或资源下限。违反约束的后果、能否恢复，都需要另行说明。
2. **有有限的缓冲。** 库存、现金、备用容量或可用时间能支撑多久，消耗与补充怎样变化；信任等社会条件需要单独操作化，不能直接当成可相加的库存。
3. **调整需要时间。** 支撑时间与调整时间是否可比较，哪些阶段已经起效，等待或切换是否产生额外损失。
4. **依赖不能完全控制的外部条件。** 如供应、融资、平台或服务；依赖本身不等于脆弱，需要比较持续性、替代路径与共同失效。
5. **当前行动改变未来路径。** 投入、退出或承诺可能扩大、收窄或重构后续选择；非行动者系统则需明确其控制机制，不把它拟人化。
6. **状态与结构不能完全预知。** 观察有限、关系可能变化，因此需要保存估计条件、竞争解释与修订触发。

个人、企业、供应链、合作安排及设备控制等对象可以具有其中一些特征。跨领域使用时，必须重新定义对象、约束、时域与证据，不能仅凭相似词汇认定机制相同。

### 哪些问题需要其他方法，哪些结论不能直接推出

- **已充分形式化的问题，优先使用相应的数学与工程方法。** 已知动力学下的可达性计算，不需要由文字框架替代；这里可协助检查目标、约束、表示与适用条件，也可结合形式化结果继续检验。
- **稳定条件下的优化或群体统计描述，可能有更直接的方法。** 若研究没有涉及持续路径或恢复窗口，就没有必要强行引入这组诊断量；表示与证据的检查仍可能有用。
- **时间长短不单独决定适用性。** 快变量或短时预测也可能涉及约束；能否分析取决于模型是否覆盖相关尺度与机制，以及证据是否足够，不能由慢变量直接推出短期变化。
- **可持续不自动等于值得追求。** 框架可以比较后果与代价，不能替代价值选择或正当性论证，见[《目标函数为什么合理？》](foundations/why-objectives-are-reasonable.md)。

适用范围本身也需要检验。具体研究应事先写明：相比直接描述或已有方法，这套表示预计多识别什么约束、提前发现什么变化，或改进什么预测；再用独立观察、反例和基线比较检查。若在所声明的条件下反复没有增益，或持续遗漏关键路径，应修订相应表示或缩小主张。
