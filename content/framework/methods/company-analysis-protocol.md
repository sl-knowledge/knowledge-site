## 0. 默认首页：只做三问和一道研究闸门

这是一种组织公司研究的起点。资料或证据不足时，可以保留未知，不必为了形成结论而填满表格。本文标题中的“操作”指研究工作流程，不指证券交易或资产操作。

| 必须回答的三问 | 最短要求 |
|---|---|
| **① 公司真实能反复创造什么经济价值？** | 一句话说明其客户高价值任务、公司特有能力/经营规则、现金循环及当前主导约束；注明至少一项直接事实。 |
| **② 今天的市场价格已经要求怎样的未来？** | 市值与基准日期、合理化该价格所需的正常盈利或现金/增长假设，至少一个具体区间；数据不足写 `UNKNOWN`，不能声称市场“还没发现”。 |
| **③ 哪项独立证据支持不同于价格假设的解释？** | 指出差异假说、独立来源与竞争解释；价格反推不是市场心理的唯一读数，资料不足就保留未知。 |

**研究资源标签：** 以下标签只分配研究精力，不代表买卖、持有、仓位或收益评级。

- **`DROP`**：核心机制被反证，或无清楚公司特有能力/可验证预期差且无保留研究价值。
- **`WATCH_DISCOVERY`**：存在强历史能力、未解的重要约束与合理变化路径，但关键证据或价差缺失；积累认知资本、暂不需投入股票资本。
- **`DEEPEN`**：有值得验证的具体预期差、独立先行证据与潜在的可实现路径；进入现金流、竞争、估值和交易深研，**不等于可以买入**。

**停笔规则：**本轮回答不了第二、三问，可输出 `UNKNOWN / WATCH`，并仅写清下一项最值钱的证据；禁止为显得完整而虚构估值或公司转型成功率。

## 1. 企业模型：一句机制，不是几十个标签

### 1.1 概念及边界

| 概念 | 具体含义 | 常见错误 |
|---|---|---|
| **Environment（E）** | 技术、需求、客户预算、价格、竞争制度、地理与监管 | 行业顺风使利润升高，就误认为公司改变了经营模式 |
| **Input（I）** | 实际订单、资金、能源、原料、客户输入 | 价格周期/资源便宜被当成竞争能力增强 |
| **Resources（R）** | 资产、知识、员工、品牌、专利、合同、股权、资金 | “拥有某资源”推断“会高效率使用它” |
| **Capacity（C）** | 研发、制造、交付、获客、服务、学习等可实际完成的任务 | 有计划或样品就认定具备大规模能力 |
| **Generator（G）** | 资源和能力如何组织、配置、转换与收费，形成可重复的经济输出 | 产品/收入增加即认为 G 被重构 |
| **Economic Output（Y）** | 营收、利润、现金、资本需求、风险、每股股东价值 | 将利润率等单个结果当作最终目标 |

Generator在本篇是经营机制的工作性称呼，不是独立的新数学对象；机制成立需要证据，不能仅靠术语命名。

**最短经济链：**`客户任务/付费约束 → 资源与能力 → 组织/产品/渠道 → 交付与竞争 → 收费/回款 → 再投资/债务 → 原股东每股现金价值`。

当必要时，以 `G=(A,Π,Φ,Λ)` 分别问：**A** 组织和连接是否改变？**Π** 人、钱、产能如何配置？**Φ** 怎样把资源转成产品和交付？**Λ** 交易条款、定价、信用和回款规则是否改变？这四个符号只用于复杂重构检查，不作为日常必须填写的数学语言。

### 1.2 明确“燃料变化”还是“发动机变化”

**经营改善的五种常见来源：**外部需求或价格环境改变；投入要素变化；现有能力投入使用率提高；运营参数/执行效率改善；组织与资本循环规则的真正重构。可能同时存在。

**主判据：**如果不改变企业的客户、信用、生产、组织与资源分配规则，仅改变需求和价格也会获得类似结果，则优先解释为环境/运营状态变化，而非新的 Generator。

从 **战略口号 → 规则改变 → 有代价执行 → 客户真实成交 → 单位经济与现金改善 → 跨周期复制**，证据才逐步由“动作存在”上升到“重构成功”。

### 1.3 当前约束与后续约束

> 在明确模型和其他条件的前提下，改变哪个条件可能影响后续每股经济结果？如果多个条件共同限制结果，需要什么联合变化？改善后，什么可能成为下一道瓶颈？

允许多个同时制约：需求、价格、产能、良率、渠道、交付、信用、融资、法规、对手、组织协调。**当前卡点松动不等于新盈利空间无限大。**

## 2. 三段研究深度，避免把全部企业写成论文

| 深度 | 何时使用 | 正式结果 |
|---|---|---|
| **初步筛选** | 初次遇到公司，信息模糊或价差未知 | 三问 + `DROP/WATCH_DISCOVERY/DEEPEN` + 1项最重要未知 |
| **命题研究** | 有理由继续研究，准备评估合理价值 | 公司经济链、现金与竞争、关键 Evidence、三情景估值、反证与更新期限 |
| **结构深研** | 真实重构、复杂股权/资本循环、重大环境突变或财务冲突 | 因果机制审计、危机时序、G结构变化、同行反事实、替代解释与压力测试 |

公开稿用文字区分研究深度，避免与后文证据失败后果的L1/L2/L3混淆；原稿研究深度标签的对应关系依次为L1、L2、L3。

**升级研究的线索：**不同报表讲述不同经营故事；财务利润与现金严重背离；跨市场新业务高度依赖未证实的资本效率；收购/子公司归属复杂；关键约束可能改变；新的价格或外部冲击显著改变生存性。

**停止追加概念：**若新增理论不能改变当前决策、最关键待证据、可证伪预测或风险控制，就只保留最简模型。研究时间本身是稀缺资源。

## 3. 实际分析顺序：十二个有先后关系的问题

### 01｜目标、时间与资料冻结

目标是研究哪个问题、采用多长时域（例如多年经营状态、未来若干季度的现金验证或某个历史价格情景）？记录截止时间、行业归属、上市主体、股数及数据时点。**禁止用结果发生后的信息填补历史判断。**

### 02｜行业与客户：真正的经济任务

客户为什么支付费用？最贵的失败成本是什么？需求由数量、频次、价格、市场份额和预算中的什么驱动？政策公布、订单和实际结算需要分开。首先画出客户、供应商、替代者与互补者，而不是先罗列公司产品。

### 03｜历史基线：普通财务与竞争分析

用同一日期资料先做一个强的常规分析：盈利来源、周期与结构增长、行业和竞争地位、现金转换、正常化估值、最强多空论据。作为未来检验复杂方法是否真正有新增价值的**对照 baseline**。

### 04｜公司特有经济 Generator

什么是这个公司能反复做到、竞争者不易同样做到的？是否通过价格、低成本、品牌、认证、渠道、服务或客户工作流真正获取付费？区别**公司控制的环节**和整个解决方案/集成商控制的环节。

### 05｜资源与能力、复制机制

是单个成功案例还是可规模化复制？新增第10、第100个相似客户/项目时，研发、人员、现场交付、存货、资本消耗怎样变化？规模大不等于复制成本低；专业企业也可以标准化。跨业务协同需以同客户复购、交叉采购、接口/研发复用和资本回报证明。

### 06｜约束、变化起因和自主选择

外部冲击迫使企业改变什么？哪些变化来自主动预见、哪些是被动求生？**被动承压而主动选择优秀路径**是合理组合，不能简单贴“主动/被动”二分。进一步辨认 G不变、效率改善、能力升级、局部/整体重构或环境激活。

### 07｜竞争者动态与反证

目标公司最可能失去哪个客户任务？对手能否通过更低成本、通用技术、接口、开放标准、并购或新的工作流绕开旧护城河？反过来公司可否低成本防御？比较双方适应速度、损失代价和增量ROIC；结局允许专家胜、平台胜、分层共存或所有人回报偏低。

### 08｜可盈利成长空间，而非抽象的TAM

从**物理/技术可能 → 客户愿付费 → 公司可进入 → 竞争后的利润率 → 增量应收/库存/投入资本 → 每股经济利润**逐层折减。旧约束改善后写出下一瓶颈、距离上限与突破成本，不得把“可用于某领域”当已形成有意义的市场。

### 09｜财务—现金—资本桥接

至少核对利润表、资产负债表、现金流量表的关键连接。原材料价格变、订单备货、存货结构、应收/票据/保理、合同资产负债、供应商账期、减值/核销、非经常损益、债务期限、资本开支、并购、少数权益、股数变化。**不能用单季经营现金流正负作好坏结论，也不能未经证明就用“战略备货”解释一切。**

### 10｜组织学习、治理、危机与资本配置

检查管理层的历史预测与实际选择，而非人格评价。危机中是否愿意放弃坏生意、保护现金、重建客户选择和授权规则、承认失败并停止投入？对比当时真实可选路径；不要用今天已知结果给过去决策贴善恶标签。其他国家/业务的风控不能凭旧市场成功自动推断已复制。

### 11｜关键 Evidence、反证与长期评级

从上述机制压缩出**1—3项最可能决定未来成败的命题**，再分别确定其 Criticality、Confidence、可观察强证据、替代解释、期限、失败后动作；不依据短期新闻数量上调评级。详见第7节。

### 12｜估值、市场假设与结论边界

在相同基准日，比较价格兼容的假设与独立的防守、基础、成功经营路径，记录资本需求、成本与模型敏感性。市场变量和候选策略的可实现性属于单独检验对象。**分别输出企业研究结论、研究资源优先级和价格假设的验证状态；本文不输出证券动作。**

## 4. 竞争、成长与资本：压缩成七条不可跳过的检验

1. **客户约束重于技术清单：**客户真正付钱买的是可靠任务完成，不是工程师能力列表。
2. **动态比较重于静态标签：**专家、平台、大企业、小企业都可能学习；AI等外部技术可扩大旧能力价值，也可使其商品化。
3. **价值归属重于社会价值：**客户节省了100，并不意味着供应商获得100；寻找收费权、切换成本归属和真正稀缺接口。
4. **业务复用重于项目数量：**收入增长是否同时带来更低的相对研发交付成本、更快的部署、更好的现金和增量资本回报？
5. **成长空间重于单个约束解除：**盒子里的植物即使浇水也无法无限生长；需求、竞争、资产与下一道约束共同限定回报。
6. **每股净结果重于规模：**母集团资源可否实际调用、谁承担研发/融资成本、子公司有多少少数股东、公司是否持续增发，必须进入估值。
7. **稳健复利与再生重估都允许：**好公司可以没有惊人的新空间；曾经很强的公司也可能再生失败。两类机会的证明责任和估值安全边际不同。

**必须避免两类偷换：**“整体系统难替换”不等于“这家供应商难替换”；“集团有现金/技术”不等于“上市公司原股东可以获得完整回报”。

## 5. 管理层与组织DNA：通过决策记录验证，不贴性格标签

所谓组织DNA是企业在不同环境下反复执行的**目标排序、权限分配、风险容忍、纠错与资源重配政策**，可以学习改变，并非管理层人格或不可变天性。

### 5.1 危机前后六段审计

| 阶段 | 必须留下的事实 |
|---|---|
| 危机前 | 当时的客户、竞争、融资、机会成本及行业周期；不能仅用后来损失认定过去全错 |
| 预警 | 哪些信号当时已能看到，管理层何时表达和行动 |
| 保全和舍弃 | 是否保住核心能力与资金缓冲，是否愿意拒绝不良订单、出售差资产 |
| 规则重构 | 是否改变客户准入、授信、交付、组织责任和资本配置，而不仅换口号 |
| 资本取舍 | 还旧债、分红、回购、收购和新增项目之间实际如何分配；是否记录停止条件 |
| 反复压力测试 | 景气恢复或进军海外时，过去建立的纪律是否仍在逆向诱惑下执行 |

### 5.2 组织学习的证据强弱

`宣示 → 制度设计 → 有代价执行 → 逆风/顺风反复遵守 → 长期风险调整后现金回报改善`。越往后越接近真正的 MetaCapacity 证据，但仍须剔除宏观顺风与账务影响。

**不同风险不能互相替代：**客户信用、付款诈骗/内部控制、海外并购资本配置、上市公司治理和股东权益各有不同的控制机制。一项制度成功不证明全部风险已解除，一次操作事故也不自动证明整个集团失去经营能力。

**反事实必须由当时信息构成：**假如公司没有做当年的扩张、收购、收缩或纠错，当时可预见的机会成本和风险是什么？避免幸存者偏见与后见之明。

## 6. 财务尽调：让账面盈利回到完整资本循环

### 6.1 不允许跳过的核算链

`客户付款与收入确认 → 经营利润 → 营运资金与经营现金 → 维护和扩张支出 → 债务与融资 → 少数权益与股数 → 每股现金价值估计`。

这是一条核对线索，不是会计恒等式或可直接逐项相减的计算公式。各层需要保持主体、期间、现金流类型和权益口径一致。

不应以单一毛利率或EBITDA替代所有层次。若公司依赖重资产但产生高于资本成本的增量回报，仍然可以是优质资产；若依赖高毛利的轻资产但应收不回，同样可能是劣质业务。

### 6.2 经营现金流发生大变化时必须做的拆解

| 变化 | 可能是好消息 | 也可能是风险 | 更有鉴别力的下一证据 |
|---|---|---|---|
| 应收增加 | 新客户/更多正常销售 | 放松信用、票据置换、坏账 | 分客户/渠道、账龄、坏账、核销、实际现金回收 |
| 存货增加 | 有订单备货、原料锁价 | 需求错估、跌价与过时 | 新订单交付、库存结构、周转、跌价准备 |
| 应付/合同负债变化 | 更好商业条款、客户预付款 | 延付供应商、预售疲弱 | 账期、现金结算和订单履约 |
| 经营现金流转正 | 销售质量提高、信用风险下降 | 季节性营运资金回落、账期变化或非经常经营收款；保理安排需核查交易实质与准则 | 滚动四季现金桥、正常化资本需求 |
| 收入大幅增长 | 有机需求及份额提升 | 并购并表、涨价、一次性订单 | 同口径有机销量、价格、贡献毛利与投后现金 |
| 资本开支上升 | 可能提升未来效率与产能 | 低回报扩产或维持既有亏损 | 项目回报、实际订单、后续折旧/现金 |

固定资产购建与长期资产处置、取得或处置子公司、筹资等，应按适用准则分别核查，不能因它们改变现金余额就都归为经营现金流。参考[IAS 7现金流分类说明](https://www.ifrs.org/issued-standards/list-of-standards/ias-7-statement-of-cash-flows/)。

**特殊行业调整：**银行、保险、券商、地产开发、建筑合同、平台业务等须遵循行业适配的资产负债/现金逻辑；不可把制造业营运资金公式机械套用所有行业。

### 6.3 公司与股东不是同一层级

关注股权归属、合资跟投、融资成本、期权/股份支付、关联交易、收购对价和少数股东分配。内部转移价格和少数权益可能导致集团收入增长而原股东的经济回报不足。

**增量经济性：**在口径一致、合理归因条件下，比较新增税后经营回报与新增资本成本；用长期每股自由现金回报检验，不能用单年波动制造虚假的精确ROIC。

## 7. Critical Evidence：决定研究结论的关键证据

这里沿用配套总纲的L1/L2/L3，只标注证据失败对命题的后果，不是研究深度、公司质量或仓位等级。Confidence记录证据支持程度，不是已经校准的成功概率。

### 7.1 每个重要命题都必须留下“证据卡”

| 字段 | 必填内容 |
|---|---|
| 核心命题 | 对象、时间与环境，例如“某新渠道能以较小信用资本占用持续赚取现金利润” |
| 失败影响（Criticality） | **L1** 核心命题塌陷；**L2** 未来成长/重估下降；**L3** 局部效率变化；须说明影响的是**公司命题还是当前买价命题** |
| 当前证明状态（Confidence） | 已有长期验证 / 早期支持 / 尚未证明 / 出现实质反证 / 信息冲突 |
| 最有分辨力的证据 | 理想的公司/客户/合同/分部及归母现金口径、可持续期数和比较基准 |
| 最强替代解释 | 宏观周期、并表增长、提价、推迟付款、补贴、财务处理、选样等 |
| 最强反证/Kill Test | 什么情况出现时必须实质下调或撤销命题，不能靠重讲故事逃避 |
| 观察时限与缺席规则 | 下次财报/两年期限；若到期仍无证据，是保持未知、降低成功信心还是停止研究，需事前指定 |
| 研究结论影响 | 哪个机制解释或价格情景需要更新，哪些资料仍缺失，何时重新评估？不生成交易指令。 |

### 7.2 正反两面都要有区分力

**错误例子：**“新业务营收同比增长20%，证明商业模式重构成功。”

**更有区分力、仍待验证的表达：**“剔除并购和价格变化后，新渠道在相近客户风险下的应收/收入、长期坏账、单位毛利和归母自由现金回报持续改善；若营收增长却依赖更长账期和新增债务，则不支持新模式成功。”

**注意：**同一口径的营收、毛利、现金变化可能同受一个宏观因素驱动，不可把高度相关证据当作三次独立验证。若竞争性解释都能产生观察结果，就需要找新的更具判别力的证据，而不是再加一页理论。

### 7.3 植物式积累和不可逆反证

日周行情或一次季报通常只能改变短期预期或局部参数，不能自动重写多年建立的 Generator 认识。若财务造假、实质债务违约、失去核心许可或不可逆重要客户退出等触发核心约束，则应立即复核 L1；长期投资不是忽视重大新信息。

**空白证据不是成功证据。**到期反复没有出现应有的客户、利润、现金或组织学习结果时，应按冻结的预测修订信心；不得持续将错误解释为“再等一季”。

### 7.4 最终先给三份结论，禁止合并为一个神秘总分

1. **企业经济判断**：已验证优质底盘 / 转型证据不足 / 结构性侵蚀 / 信息不足；写主导机制、约束和 L1/L2/L3 未决事项。
2. **研究闸门**：`DROP / WATCH_DISCOVERY / DEEPEN`；按信息的潜在增量价值分配研究注意力。
3. **价格与候选策略研究状态**：假设已记录 / 数据不足 / 待独立检验 / 已有反证。它不等于证券操作建议，也不根据前两项自动导出买卖或仓位。

## 8. 匿名教学比较：失败后果与证据支持不是同一轴

原稿以两家真实企业的截至2026-10-11研究状态说明证据分层。其公司事实与数值没有在本次发布时逐项重新核验。为避免被误解为当前评级，公开稿改成以下匿名教学情境；它们不是对真实企业的替代披露，也不保留股票代码。

| 项目 | 教学情境A：现金循环重构尚未证实 | 教学情境B：既有业务有支持，新增空间尚未证实 |
| --- | --- | --- |
| 研究前提 | 已观察到渠道或信用安排变化，但改善效果未知 | 模型暂保留既有经营能力，新增业务效果未知 |
| 核心未决命题 | 新规则能否形成可持续、较低信用消耗的现金回报？ | 新任务能否带来竞争后的利润与归属原股东的现金？ |
| 失败后果 | 若原命题必须依靠新现金循环成立，它可能属于L1 | 若既有业务假设仍成立，新增空间可能主要影响L2 |
| 缺少的区分证据 | 同口径应收、账龄、信用损失、有机收入和资本占用 | 客户付费与复购、独立现金、少数权益、复制成本 |
| 竞争解释 | 需求顺风、并表、账期延长、风险外移 | 周期改善、少数客户、补贴或一次性收益 |
| 研究记录结果 | 写明哪些命题未获支持及下一观察，不给证券评级 | 分开记录已有支持与新增假设，不因“好公司”标签推导动作 |

上述后果等级仍依赖具体命题和价格情景。如果某种价格假设必须依赖新增业务高度成功，它的证据缺口也可能成为该假设的L1；A情境若逐渐获得可靠现金证据，未决问题的后果也可能收缩。

这一比较说明的是**未证明什么，以及若不成立会影响哪项结论**，不排列股票收益，不提供相对配置或买卖结论。

## 9. 可追溯的案例研究记录模板

> **公司／代码：**`____`　 **事实截止日：**`____`　 **研究目标/时域：**`____`
> **资料完整度：**`足够/不够/冲突`　 **结论状态：**`暂定/需复核`

| 顺序 | 内容（只填写决策有关的事实和假说） |
|---|---|
| **1. 核心经济机制** | 客户任务、实际 Generator 及公司独有的价值控制点；最有力的两项直接事实 |
| **2. 当前环境和旧/新约束** | 需求、竞争、客户预算与政策的变化；主导约束、解除机制、下一瓶颈 |
| **3. 业务及资本经济性** | 有机增长与并表分别怎样？毛利、正常化利润、OCF/FCF、资本与信用、少数权益、每股价值 |
| **4. 可盈利成长空间** | 新增可进入需求、竞争反应、毛利/现金资本成本、旧业务下行，五年后可能的上限 |
| **5. 组织DNA/纠错** | 历史决策—当时环境—真实结果—修正动作；未来可证伪的组织行为 |
| **6. 最危险的竞争/财务反证** | 对手/替代最容易如何击穿？何种现金/信用/资本安排会形成不可逆风险？ |
| **7. 最关键的证据①（优先 L1）** | 命题 + L1/L2/L3 + Confidence + 最佳直接证据 + 竞争性解释 + 截止期/Kill Test |
| **8. 最关键的证据②③（可无）** | 仅保留真正能改变长期研究结论的关键证据，不填充普通季度 KPI |
| **9. 情景与估值** | 防守/基础/成功下每股现金价值、关键假设；现价隐含何种未来；资料不足写 UNKNOWN |
| **10. 基本面长期评级** | 哪些是已证明底盘，哪些未证明，哪些开始受损；与上次相比因何事实调整 |
| **11. 研究资源闸门** | `DROP/WATCH_DISCOVERY/DEEPEN`；未来一至三项值得新取的证据 |
| **12. 价格与策略假设的验证状态** | 估值假设、资料时点、成本和可实现性是否已有证据；缺口单独列出，不记录面向读者的买卖或仓位指令 |
| **13. 下次复查** | 财报/政策/客户证据日期；不能无限延期的观察截止期 |

### 事件更新的最短记录

`记录时间与信息可得时间｜资料与原文口径｜事实/声明/推论/假说/未知｜影响哪个命题｜证据独立性｜支持/反证/无关｜长期评级有无变化及理由｜价格情景与策略假说是否需要修订｜下一证据与复查期限`。

此前记录应保存为只读快照；新证据只追加，不回写原预测。允许重新建模，但必须标出是模型修订而非最初就已知道。

## 10. 资料标准、边界条件与现实检验

**证据优先序：**法定公告和财报、交易所/监管披露、客户和合作方独立证实、产品验收/真实回款、行业与官方统计、可信第三方研究；管理层交流须与真实经济结果区分。社区意见只可当线索。

**事实标签：**`FACT`（直接事实）/ `REPORTED`（第三方或管理层主张）/ `INFERENCE`（分析推断）/ `HYPOTHESIS`（尚待证）/ `UNKNOWN`（资料缺失）/ `CONTESTED`（证据冲突）。必须核查主体、期间、归属、报表口径、单位、同环比、是否并表及是否可比。

**跨域参考的严格次序：**先用目标公司事实形成一个机制性 Signature（目标、活动、约束、可重复规则、失败机制）→ 用这个 Signature 寻找其他行业同构候选 → 验证关键机制及边界是否保留 → 只迁移能够被本公司事实检验的预测。相似故事不是证明。

**反偏差外部检验：**公司研究必须与强传统基线比较；纳入没有转型、转型失败或市场完全定价的样本；对于已发生的历史事件必须避免后视信息和生存者偏差；不因为一个复杂案例使整套语言继续膨胀。

**绩效尚未证明：**能够写出一套可信公司模型，不意味着它在真实交易中必然跑赢市场。最终仍要以前瞻冻结预测、样本外判断、净费用后的实际收益与风险来检验。若新增语言不改善这些结果，应简化或删除。
