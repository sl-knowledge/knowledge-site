## 一、CF Grammar 试图帮助我们做什么？

研究一个企业、一座工厂或一个人的计划，常常会得到一长串因素：技术、资金、资源、权限、组织、时间和外部变化。困难不只在于资料不足，还在于不知道哪些因素真正改变了当前问题的答案。

CF Grammar 提供一组诊断问题：我们分析谁？希望达到什么目标？期限是什么？什么提供支持，什么限制行动，什么暂时吸收冲击，什么可以替代？这些关系一旦变化，哪些路径会出现或消失？

它的用途是把杂乱事实组织成可检查的候选表示，帮助选择下一步的专业模型、观察或实验。给一个因素贴上“约束”的标签，并不能完成因果识别；一张关系图也不能替代工程计算、财务分析、制度研究或行为证据。

原 v0.3 已把自己定位为领域语义之上的诊断覆盖层。后续[总架构](./research-architecture.md)进一步将它定位为 **Diagnostic Scaffold，即发现候选表示的诊断支架**。它帮助提出和整理假说，再由适用的领域知识、成熟方法和现实反馈检验这些假说。

## 二、每个判断都需要主体、目标、环境与时域

“缺钱是约束”这句话还不完整。对谁而言？需要多少、何时需要？目标是不断供、提高产量，还是降低成本？资金是否已经承诺、能够支配并及时到账？

一次分析至少应说明四项条件：

| 条件 | 要回答什么 | 教学示例 |
| --- | --- | --- |
| 主体 System | 谁的行动与状态受到分析？ | 一座工厂 |
| 目标 Target Profile | 什么必须满足，什么只是期望或优化方向？ | 未来30天不断产；在此前提下控制成本 |
| 环境 Environment | 哪些供应、规则、资源与其他主体有关？ | 原供应商停供，备选供应商需要认证 |
| 时域 Horizon | 判断针对何时，行动需要多久生效？ | 现有库存与认证所需时间 |

目标不必强行压成一个总分。安全条件、交付阈值和成本优化可以承担不同角色；有些目标之间暂时无法比较，也是需要记录的结果。

同一个因素，在不同期限和环境中可能具有不同作用。新供应商可能在半年计划中可用，却赶不上下周的库存缺口。更长时间也不自动带来更多选择，因为等待期间可能发生资源耗尽、竞争变化或条件撤回。

## 三、四类关系，以及它们不自动证明的事情

v0.3 将关系族控制在较小范围。下面的句式是诊断入口，使用时仍须补足目标、维度、情境和证据。

| 关系 | 工作含义 | 需要进一步检查 |
| --- | --- | --- |
| 支持 enables | 某条件使目标相关的能力或结果更可能实现 | 支持到什么程度，是否还有其他必要条件？ |
| 约束 constrains | 某条件限制允许的状态、动作或转移 | 是硬性不可行、阈值未满足，还是成本表现不佳？ |
| 缓冲 buffers | 暂时吸收、延迟或减弱扰动，帮助维持目标可行 | 缓冲剩多少、消耗多快、在哪些情景下失效？ |
| 替代 substitutes_for | 在指定功能和维度上提供足够的替代 | 是否及时可用，有什么代价、依赖和副作用？ |

库存可以缓冲停供，但库存并没有恢复供应；备用路线可能替代原路线，却未必满足同样的速度和成本要求。“缓冲”和“替代”因此不能只凭结果暂时没有恶化就混用。

还要区分关系与状态。“供应限制了生产”是一项关系判断；“它是当前绑定约束”则进一步声称，这项限制正在实质约束目标相关的可达或可持续路径。并非所有不利因素都具有同等地位。

一个有用的反事实问题是：在明确固定其他条件、允许哪些配套变化以后，缓解这个因素会不会改变可行路径或决策？如果多个约束共同起作用，单独放松其中一个可能看不到改善，不能据此自动宣布它无关。

“主导约束”应是有条件的诊断结论。不同约束影响不同目标时，可以保留并列、联合或不可比较的判断，不需要为了得到一个排名而编造统一强度分数。

## 四、有能力，是否就意味着现在能用？

资源存在、能够获取、具有控制或授权、能够按时投入使用，是不同的条件。CF 用 **Operational Actionability，可行动性** 提醒研究者逐一检查这些差异。

一条备选生产线即使技术上可行，也可能受设备、认证、人员、权限和建设周期限制。它存在于方案清单中，不等于能够应对眼前期限内的风险。

在后续[统一术语](./canonical-vocabulary.md)中，Capability 强调系统自身能较可靠调用的能力；Access 则强调来自外部、当前可调用而不完全由自身控制的资源或通道。外部支持可能长期稳定，内部能力也可能退化，关键是把实际控制、依赖与撤回条件说清楚。

这也解释了为什么“自由”在技术分析中需要展开：

- **可达性：** 在指定条件与期限内，能到达哪些状态？
- **可生存的选择：** 到达之后，是否仍保留满足约束的持续路径？
- **适应能力：** 环境改变后，是否能及时调整、替代或重构？

有很多表面选项，可能仍然赶不上期限；能到达一个状态，也可能无法在那里持续。本文保留“自由”作为自然语言上位词，具体研究应交代正在讨论哪一类问题，以及模型、场景和未知条件。

## 五、一项诊断断言怎样写得可追问？

v0.3 的重要设计，是以情境化断言组织判断，而不只写两个名词之间的一条箭头。下面给出一个人类可读的示例，供研究记录使用；它不是已发布的软件字段标准，也不是现实企业数据。

```yaml
断言编号: factory-supply-01
主体: 教学工厂A
目标:
  必须满足: 未来30天维持规定的生产任务
  优化方向: 在此前提下控制成本
环境: 原供应商停供，备选供应商尚需认证
时域: 30天
关系: constrains
来源因素: 关键材料的持续供应条件
受影响对象: 维持生产任务的能力
诊断状态: 候选绑定约束
机制假说: 当前库存不足以覆盖停供期，且尚无及时可用的替代
待检查证据:
  - 库存、耗用率与所需材料规格
  - 恢复供货时间及其不确定性
  - 备选认证、产能、运输和授权条件
修订触发:
  - 获得足量且及时可用的替代材料
  - 发现其他因素已先行限制生产任务
记录性质: 教学示例，未验证
```

这个记录将“我们在主张什么”与“我们有什么证据”分开。字段写得完整，仍可能提出错误的机制；标注高置信度，也不会使相关关系自动变成因果关系。

如果新信息只是降低库存估计，就更新证据和参数；如果发现材料并不短缺，停产其实来自设备故障，就需要修订机制和表示。记录的意义在于让修改有迹可循，而不是让一项判断显得正式。

## 六、从诊断走向预测：关注什么会先发生

预测层笔记把问题进一步展开：当前约束可能通过缓冲、解除、替代或重构得到响应；哪些机制实际可用，何时生效，期间能否维持目标？若有效，应先出现什么变化，下一约束又可能在哪里？

以教学工厂为例，假设按当前耗用率，库存可维持约10天，备选材料认证与交付估计需要7天。这提供了一条值得检查的候选路径，却不能直接推出“可以安全度过停供”。还要检查认证失败风险、供应数量、规格、运输、后续持续供货，以及库存估计的误差。

如果机制生效所需时间比缓冲剩余时间更长，当前路径就存在明显的时间缺口；反过来，时间上赶得及，也不保证力度和持续性足够。因此，“适应时间小于缓冲期限”只能作为检查线索，不能当作普遍成功定律。

一项更可检查的前瞻记录，应提前说明条件与期限：先完成认证，再形成有效订单并交付合格材料，随后观察供应是否足以维持生产。若认证完成而没有稳定交付，就不能把“流程推进”当成目标已经实现。

供应恢复后，机器产能可能成为新的限制，但这是候选的约束迁移路径，仍需用订单、工时、停机和产量等证据区分。原预测笔记明确将机制选择顺序与约束迁移的预测优势列为待验证问题，本文沿用这一研究状态。

## 七、怎样把 CF 放回完整研究闭环？

CF 只承担一部分工作。完整流程还需要从证据构造竞争表示，选择适用方法，形成条件化预期，再根据反馈修订。

```text
明确真实问题、目标与时域
  → 获取并核对领域证据
  → 用CF问题组织候选关系和机制
  → 保留能够改变判断的核心差异，同时监测重要未知
  → 比较竞争解释，调用适用的领域模型
  → 记录条件、预测、领先观察和失败判据
  → 观察现实，定位偏差，修订表示
```

有时预测失败，是遗漏变量或机制判断错误；有时是环境与结构变化；还有时，模型没有改变，只是被用来回答另一种目标或时域的问题。后续书稿将这些问题归入表示发现与表示失效研究，不能只靠不断给原图添加新标签应对。

变量管理也需要层次。当前已知影响目标判断的进入核心；可能重要但证据不足的继续监测；其余材料可以归档。当前没进入模型，不等于永远没有作用。

具体方法可接着阅读[我们如何知道什么值得进入模型](../book/what-belongs-in-a-model.md)和[不确定世界中的行动](../book/acting-under-uncertainty.md)。

## 八、一页检查单与验证边界

实际研究时，可以先回答七个问题，再按需要展开：

1. 分析谁，在什么环境中，要在何时满足哪些条件？
2. 哪些是状态、输出、内部能力、外部通道与机制假说？
3. 哪些条件支持、约束、缓冲或替代目标相关的能力？
4. 候选动作是否具备资源、权限、依赖和及时生效的条件？
5. 哪个限制正在改变可达或可持续路径，反事实依据是什么？
6. 如果响应有效，应先看到什么；什么证据会使我们修订解释？
7. 哪些未知继续监测，下一步什么观察最能区分竞争解释？

这是一份综合整理的工作清单。它能否降低遗漏、改善预测或节省研究成本，需要与普通摘要、传统清单和适用的成熟方法比较。能把许多事后案例讲通，不足以证明前瞻价值；术语跨领域复用，也不足以证明机制可以直接迁移。

公开的应是可理解、可复查、能接受失败的研究工具。本文不把小规模教学例子当作实证结果，也不将预测层升级为已经验证的规律。相关检验安排见[原创性自查与独立验证计划](./originality-and-validation.md)。
