## 导读

我们常用自己的标准判断别人，却很少把这个标准本身当作问题。一个人觉得另一种说法太绕，可能是因为那种说法确实让人难懂，也可能是因为他习惯了另一种组织语言的方式。要看清是哪一种，得先说出自己凭什么作判断。

本文把从判断内容转向观察判断框架的动作称为**二阶反思**。它可以用在别人身上，也可以回到自己身上。看见一个框架之后，可以继续追问它怎样形成，再检查它在什么情况下好用、会漏掉什么。文末给出可检验的猜想和一份清单。

## 1. 从判断内容到看见框架

本文所说的**框架**，是人在作判断时采用的区分、纳入的信息和所用的标准。例如，判断一句话是否清楚时，有人主要看它紧不紧凑，有人主要看听者能不能按顺序复述发生了什么。

| 观察的位置 | 典型问题 |
|---|---|
| **一阶**：在框架内判断 | 这句话讲清楚了吗？ |
| **二阶**：把判断框架当作对象 | 他用什么标准说这句话讲清楚了？这个标准让他注意什么？ |
| **反身的二阶**：把同样的问题用在自己身上 | 我凭什么判断它讲清楚了？我采用的标准让我漏掉了什么？ |

这里有两个层次。反身的二阶是二阶反思转向自身。能指出自己把紧凑当作清楚的标准，就已经看见了框架的一部分。这个习惯是怎样养成的，还要另作解释。

## 2. 两个例子：说话的人怎样组织同一件事

这里观察的是说话的人，以及他们用什么标准判断一句话讲得清不清楚。两个例子都可以先问一件事：在这个场合，听者实际听懂了多少？

### 把一件事放进名词短语，或用分句讲出来

- *The committee’s rejection of the proposal surprised us.* 把「委员会否决了这个方案」放进一个名词短语，整件事成了句子的主语。
- 「委员会否决了这个方案，我们没想到。」先用一个分句交代否决，再用一个分句说我们的反应。

两种说法都先交代否决，再交代反应。英语也可以用两个分句，*The committee rejected the proposal. We hadn’t expected that.* 中文也可以用名词短语，「委员会对这个方案的否决出乎我们的预料」。有人觉得把事情放进一个短语更紧凑，有人更习惯一句讲事情、下一句讲反应。同一个人也可以随场合换用。

### 把信息在句子里说出来，或留给上下文

有人问「你昨天做了什么？」同一件事，可以这样回答。

- 普通话：「昨天看了两部电影。」
- 英语：*I watched two films yesterday.*

普通话的回答里，从问话就知道答话的人在说自己，「我」可以省掉。「昨天」交代了时间，「了」表示看电影这件事已经发生。「两部」说明数量，「电影」的形式照旧。在英语这个完整的陈述句里，主语 *I* 说了出来。即使已经有 *yesterday* 和 *two*，这里仍用过去式 *watched* 和复数 *films*。

两种语言都可以借助上下文。英语在随意的对话里也会省略主语。普通话在需要指明或强调是谁的时候，也可以把主语说出来。这里比较的是在同一个场合，说话者如何在句子和上下文之间分配信息。有关时间、数量和主语的研究见第 9 节。

习惯普通话这种说法的人可能会想：「都在问我了，还要再说一遍‘我’吗？都说了‘昨天’和‘两部’，为什么‘看’和‘电影’还要变？」习惯英语完整陈述句的人也可能觉得：「把谁看的也说出来，句子才完整。」两个人都可能在用自己熟悉的方式作标尺。

**我的假设是，当两种说法都能把同一件事讲明白时，一个人可能觉得自己更熟悉的那种更自然，并因此倾向于把它评价为更清楚。**

这时可以分别问两件事：听者从这句话和上下文里实际懂了什么？我觉得哪种说法更顺，又是根据什么把它判断为更清楚的？

| 说话者做的事 | 看到了什么 |
|---|---|
| 用最熟悉的方式评判另一种说法 | 觉得对方把句子说绕了，或觉得对方少说了该交代的事。 |
| 能在两种说法之间切换 | 知道同一件事可以用不同方式组织，也可以根据场合把一部分信息留给上下文。 |
| 看见对方采用的标准 | 能指出对方重视的是说法紧凑、顺着事情讲，还是在句里把关键信息交代齐全。 |
| 用同样的问题看自己 | 能把自己的熟悉感和听者实际理解了什么分开看。 |

会切换两种说法的人，仍可能把自己最熟悉的一种当成默认。接触另一种表达方式，给了人察觉自身习惯的机会。察觉之后，也仍然可以有自己的偏好。

## 3. 把框架看作表现型

看见框架后，可以把它当作某些形成过程在具体条件下留下的结果，也就是本文所说的**表现型**。经历、环境和需求是解释线索。比如，比较同一个人写报告和讲故事时怎样组织类似的事件，可以看到他在不同场合选用什么说法。若进一步推测他是长期写报告才养成了某种习惯，就要回看他的表达从何时开始改变，当时还有哪些条件也变了。

理解先于评价，可以落实为三个问题。

1. **它怎样形成？** 有哪些经历或条件促成了这个框架？
2. **为什么有人接受它？** 它对当事人解决了什么问题？用他自己的标准看，为什么说得通？
3. **它的主张经不经得起检查？** 可以独立核对哪些证据？用了这套标准会漏看什么，代价由谁承担？

一个框架怎样形成、为什么有人接受它，各有自己的证据。判断一个主张能否成立，还要看支持主张的证据。用来评价它的标准也有自己的形成条件，同样可以拿来检查。

## 4. 看清与选择

看清一个框架怎样形成之后，人仍然要说明自己依据什么标准来选择。朋友刚问你昨天做了什么，直接说「看了两部电影」就够了。要把这句话单独写进一份记录，以后还有人要查是谁看的，就值得把人写出来。说到什么程度，要看听者已经知道什么，以及这句话之后会怎么用。

> **几阶思维不决定选择什么，但会影响怎样持有自己的选择。**

反思给人多一个检查自己选择的机会。一个人可以继续坚持原来的选择，同时说清它为了什么、何时适用，以及出现什么情况就该重新考虑。

## 5. 为什么需要回过头来检查自己

正在使用的框架，很难在当下看全。熟悉的标准往往不用想就会拿来用。缺少对照时，它容易显得理所当然。事情还关系到自己的身份或长期投入时，人也可能更难停下来检查它。

意识到框架的某一部分之后，到了另一个情境，人仍可能按熟悉的方式作判断。因此，反身的二阶需要一次次回到。要观察一个人是否回到了这一步，可以看他能否**指出自己用了什么标准、识别一项可能被忽略的因素，并说清什么证据会让他调整标准**。满足这些条件以后，才有意义记录他花了多久。也可以另看他能否在新例子里做到同样的检查。

## 6. 怎样检查自己的框架

假设我听完一段话，认为说话者漏掉了一个关键步骤。回去逐句核对，发现那一步其实说过，我就修正了这一次的判断。再往前问一步，我发现自己常把“说得紧凑”当成“讲得清楚”的依据。现在要检验的是这条标准本身。

我可以准备两段文字，让它们交代相同的关键步骤，再请读者复述。如果我原先认为较紧凑的版本更清楚，读者却从较长的版本里复述得更准确，就有理由在这个任务里把“紧凑”和“讲清楚”分开评估。两项各有多重要，要看任务。这时我检查的是自己一直拿什么来判分，以及这条标准在什么条件下有用。

- **事先写下判据。** 分别写下什么观察会推翻这一次的判断，什么观察会让自己修改所用的标准。
- **请别人指出漏项。** 问对方依据什么得出不同结论，请他指出自己在考虑什么，而我漏了什么。
- **用新例子再试一次。** 看修改后的标准能否解释旧例子的差别，也能否用于另一个例子。行动可以按目前的判断推进，同时记下什么情况出现后要重新检查。

## 7. 可检验的猜想

1. 能明确指出自己评价标准及其边界的人，在面对陌生观点时，可能更快做出当事人认可的复述。可以换一个案例测量复述质量，并把理解速度和敌意等态度分别记录。
2. 同一个人面对与自身身份或长期投入有关的问题时，可能更容易沿用原有标准。可以用难度相近的问题作对照，观察他能否达到第五节所说的检查条件。
3. 事先写下什么证据会动摇自己标准的人，遇到相应的反证时，可能更容易重新检查这个标准。要分别记录他有没有检查，以及检查后的修订是否有依据。
4. 反复练习先复述对方的框架，再检查自己的比较标准，可能让人更擅长在新案例中做同样的事。可用未练习过的材料检验这种变化。

## 8. 清单

1. 我是在核对一个判断，还是在检查作出判断时用的框架？
2. 对方用什么标准？我能否先把他的理由复述到他认可，再核对主张的依据和代价？
3. 哪些条件可能让他的框架长成这样？如果我的解释对，条件改变后应该看到什么差别？
4. 我用了什么标尺？即使换了一套更精致的理论，我是否仍把熟悉的标准当作唯一标准？
5. 这个标准可能漏了什么？什么样的证据会让我调整它？能否找一个新例子再试？
6. 理解过后，我依据什么作选择？这个标准在哪些情况下应重新检查？

## 9. 与前人工作的接口

| 前人工作 | 与本文的关系 |
|---|---|
| Collingwood 的二阶思想 | 把对对象的思考也当作思考对象，可与第一节对照。 |
| Kornblith 等关于反思的认识论讨论，Flavell（1979）的元认知 | 前者追问反思与信念可靠性的关系，后者提供观察自身认知活动的视角。本文具体讨论用于判断的框架。 |
| Luhmann 的二阶观察，von Foerster 的二阶控制论 | 前者提供观察另一个观察者如何作区分的视角，后者把观察者纳入考察。两者与本文把同一问题用于他人和自己相接。 |
| Kegan 的主体—客体转换，Bateson 的学习层级，Argyris 与 Schön 的双环学习 | 分别提供把习以为常的结构当作对象、考察框架如何改变，以及在行动中检验支配前提的对照。 |
| Boas、Sapir 以来的描写语言学，Slobin（1987）的 [*Thinking for Speaking*](https://doi.org/10.3765/bls.v13i0.1826)，香港中文大学 [NV Atlas](https://nvatlas.tra.cuhk.edu.hk/about.html) | 为描述语言用法、考察说话时怎样组织经验，以及比较字幕里的英语名词化与中文动词表达提供参照。第二节关于熟悉感可能影响清楚程度的评价，是本文的假设。 |
| [Lin（2003）](https://doi.org/10.1023/A:1023665301095)、[Cheng 与 Sybesma（1999）](https://semantics.uchicago.edu/kennedy/classes/f11/na/docs/chengsybesma99.pdf)、[Huang（1984）](https://ctjhuang.scholars.harvard.edu/sites/g/files/omnuum5106/files/ctjhuang/files/1984_empty_pronouns.pdf)、[Weir（2012）](https://biblio.ugent.be/publication/6858530) | 分别供核对普通话的时间表达、名词与量词、普通话的主语省略，以及英语在特定语体下的主语省略。 |
| Hume 关于事实与规范的区分，Weber《以学术为业》 | 可与第四节对照。理解一种立场的来由和后果之后，选择还需要自己的价值依据。 |

本文把这几项工作接在一起，从看见判断用的框架，走到考察它形成的条件，再以具体例子检验它的用处和边界。问别人的问题，也用来问自己。
