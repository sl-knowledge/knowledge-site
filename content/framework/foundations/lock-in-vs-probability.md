# 平稳不等于有退路：出问题的概率与被锁定的概率

**SL · 公开研究稿 v0.4 · 2026-11-03**

> **核心问题：为什么日常表现良好的方案，可能在持续选择中保留下尚未暴露的恢复缺口？这种缺口的风险后果，应当怎样评价？**
>
> 本文的定位：用"日常表现"与 p、q、s 三个量，解释[《简化与退路》](https://sl-knowledge.github.io/knowledge-site/framework/foundations/simplicity-and-recovery#sf9) SF9 所讨论的筛选机制，并说明它的风险后果。SF9 已给出有限测试怎样让有缺口的方案被选中、缺口怎样被持续保留；本文不重复提出这一机制，而是给出评价其后果的口径。
>
> 本文讨论抽象结构，不分析具体事件或对象。编号 LK1—LK6 用于引用；编号不表示各项具有相同的证明地位。本文与既有研究的关系见第八节，原创性仍待系统核对。

---

## 一、要分开评价的几件事

比较两个方案时，人们常常把几件不同的事混在一起：

1. **日常表现**：平常顺不顺、波动大不大、成本高不高；
2. **出问题的概率**：遇到所定义的问题的可能性有多大；
3. **出问题后失去恢复能力的可能性**：问题发生以后，还能不能回到可接受的状态；
4. **失去恢复能力以后的后果。**

第一件事每天都看得见，后三件事平常大多看不见。本文的主张是：**这几件事必须分别评价；日常表现好，既不说明出问题的概率低，也不说明出问题以后还能恢复。**

---

## 二、三个量及其条件

<a id="lk1"></a>

> **LK1　在固定的方案、初始状态范围、时域与可用资源下，可以把"失去恢复能力"的风险拆成三个量分别讨论。**

在同一概率模型与观察时域内，设 A 为所定义的问题事件（例如遇到某一强度以上的扰动），L 为进入所定义锁定状态的事件（见第三节）。比较方案时，还需固定或明确调整初始状态分布、扰动分布与暴露口径。

| 量 | 定义 |
|---|---|
| p = P(A) | 发生问题 A 的概率 |
| q = P(L \| A) | 问题发生后，进入锁定状态 L 的条件概率 |
| s | 进入 L 之后的损失或后果，需另行定义 |

如果进入锁定必然经过问题 A，那么：

> **P(L) = p · q**

当 \(p>0\) 时，这一关系来自条件概率的乘法法则，不需要额外的独立性假设。

若锁定也可能在 A 未发生时形成，例如资源在日常运行中逐步耗尽，则一般关系是：

\[
P(L)=P(A)P(L\mid A)+P(A^c)P(L\mid A^c),
\]

其中每个条件概率仅在其条件事件概率为正时使用；若某条件事件概率为零，对应项按联合概率记为零。只有 \(P(L\cap A^c)=0\) 时，才可将整体锁定概率简写为 \(p q\)。因此，“经 A 进入锁定的风险”与“全部锁定风险”不能混用。

s 可以表示损失的分布、区间或指定评价量。若要计算锁定损失的期望贡献，可定义 \(s=E[S\mid L]\)，在条件期望存在时写作 \(P(L)s\)；这不包括未锁定情形的其他收益与损失，也不是唯一的风险评价标准。

这一拆分的用处，是让人看到只比较 p 时会漏掉的东西。但它同时说明：**不能只凭 q 较高，就判定一个方案的整体锁定风险更高**。一个纯数学的例子，设两者后果相同：

- 方案甲：p = 1%，q = 90%，锁定概率为 0.9%；
- 方案乙：p = 10%，q = 10%，锁定概率为 1%。

方案甲的 q 高得多，整体锁定概率却略低。所以，比较方案时需要看 P(L) 和 s，而不是只看 p 或只看 q。

这与[《不确定世界中的行动》](https://sl-knowledge.github.io/knowledge-site/framework/book/acting-under-uncertainty)的出发点一致：同样的成功概率，可以对应完全不同的损失与恢复时间；可能终止整个过程的失效方式，要单独定义并控制暴露。

## 三、什么是"锁定"

<a id="lk2"></a>

> **LK2　本文所说的锁定，指在给定时域、资源与允许动作下，无法恢复到所定义的可接受状态。**

这一定义有三点需要说明：

1. **它是相对的**。在一个时域、一组资源和动作下无法恢复，换一个时域或增加资源，可能就能恢复。"暂时恢复困难"不等于"永远不可逆"。
2. **它要与"当前政策缺少恢复保证"区分开**。[《简化与退路》](https://sl-knowledge.github.io/knowledge-site/framework/foundations/simplicity-and-recovery)中的恢复范围，要求同一政策在全部声明扰动下都能恢复。状态离开这个范围，可能只说明当前政策在某些扰动下不能保证恢复；换一套政策，仍可能恢复。本文的锁定指更强的情形：**在给定资源、信息与允许动作下，已经没有任何恢复办法**。相应地，q 指的是问题发生后进入这种状态的条件概率。若另以 \(B_\pi\) 表示"当前政策不能保证恢复"的事件，可定义 \(q_\pi\) = P(\(B_\pi\) | A)。只有两者使用同一个 A、概率模型、时域、资源、信息与扰动范围，且 L 包含于 \(B_\pi\)（允许的候选政策包括当前政策）时，才有 q ≤ \(q_\pi\)。有限测试未找到恢复办法，不等于已经证明不存在恢复办法；模型内的上界也不自动是真实系统的可信上界。路径与恢复的术语见[统一术语](https://sl-knowledge.github.io/knowledge-site/framework/methods/canonical-vocabulary#path-objects)。
3. **锁定有多种生成方式**。一类常见的方式是"阈值加正反馈"：在某条界线以内，负反馈占上风，扰动后能回来；越过界线，偏离自我加强。但锁定也可能来自资源耗尽、通道关闭、时限已过等其他方式。本文不把任何一种当作唯一的机制。

怎样估计离锁定还有多远、q 有多大，本文不作限定。可用的方法包括：直接计算恢复范围、结构化情景与压力测试、比较历史上的恢复时间、检查到各项约束的距离；在具备相应结构的系统中，也可以借用分岔与临界转变模型的方法（见第八节）。

## 四、日常表现与恢复缺口

<a id="lk3"></a>

> **LK3　按日常表现选出的方案，可能运行在离锁定更近的位置。日常表现好，不说明 p 低，更不说明 q 低。**

日常表现与 p 是不同的量。去掉冗余可以降低日常成本，但不会降低外部扰动发生的概率；把运行区间收窄可以让日常更平稳，但扰动照样会来。这类改变影响的主要不是 p，而是**扰动来了以后**会发生什么：

- 缓冲越少，同样的扰动越容易耗尽资源；
- 运行越靠近边界，同样的扰动越容易越过界线；
- 越针对常见扰动优化，对少见扰动的应对能力可能越弱。

所以，在不少情形中，提升日常表现的改变会提高 q。这不是普遍规律：有些改变同时改善日常表现和恢复能力，有些改变对两者都无影响。但在"日常表现是主要筛选依据"的情况下，这种此消彼长容易被忽视。

生态学家 Holling（1973）区分了**稳定性**与**韧性**：稳定性指受扰动后回到原状的倾向，韧性指系统能承受多大的扰动而不被推入另一个状态；系统可以保持局部稳定，同时吸引域缩小、韧性下降。Carlson 与 Doyle 的"高度优化容忍"则指出：对预期扰动的优化，可能伴随对未预期扰动的脆弱性。LK3 借用这两项观察，把它们用于"方案怎样被选出"的问题。

## 五、恢复缺口怎样在持续选择中被保留

<a id="lk4"></a>

> **LK4　按日常表现筛选方案时，恢复缺口可能被持续保留；要进一步说选择过程"偏向"这类方案，还需要更多条件。**

[《简化与退路》](https://sl-knowledge.github.io/knowledge-site/framework/foundations/simplicity-and-recovery#sf9)的 SF9 已讨论了这一机制：有限测试怎样让有缺口的低成本方案被选中（9.2），以及检验覆盖、选择标准与更新条件怎样使缺口持续保留（9.3）。本节不重复这一机制，只用本文的量重新表述它，并说明从"可能保留"到"产生偏向"之间还差哪些条件。

**用本文的量来表述**。日常表现通常较易观察。在口径与运行条件可比时，p 可由足够的运行记录估计；仅凭日常记录，通常难以识别 q 与 s。一条事件记录显露的是一次结果，并不直接给出条件概率。形式分析、压力测试、历史比较与其他独立证据，可以在事前评估恢复缺口及其后果，但需要说明模型假设与误差。因此，若筛选主要依据日常表现，又缺少这些额外检查，带有恢复缺口的方案可能长期不被纠正。

**从"可能保留"到"产生偏向"，还需要以下条件：**

1. **候选中确实存在带恢复缺口的方案；**
2. **这类方案在日常评分上具有优势**，例如成本更低、波动更小；
3. **保留、淘汰与更新的规则是明确的**，且主要依据日常评分；
4. **少见扰动缺乏反馈，失败不能及时触发修订**（对应 SF9 的 9.3）。

只有前三个条件也成立时，才能说选择过程系统性地偏向这类方案；仅凭第 4 条，只能说缺口可能缺少纠正信号。

## 六、一条候选的筛选规则

<a id="lk5"></a>

> **LK5（候选）　当锁定的后果不可接受且难以逆转时，比较方案应以锁定概率 P(L) 或其可信上界作为约束，而不只比较 p 或日常表现。当 P(L) 难以估计、但某方案的 q 明显偏高时，可把它列为优先审查的对象。**

这条规则需要几点说明：

- 它依赖一个额外的价值判断：**某些后果不可接受**。这个判断不能由概率拆分本身推出，需要在具体问题中明示。
- 它不是"排除高 q 方案"的普遍规则。第二节的例子说明，高 q 方案的整体锁定概率未必更高。
- 它与[《控制权、信息与时间》](https://sl-knowledge.github.io/knowledge-site/applications/viability-first-control#c17)的 C17 方向一致：在无法认证安全动作时，显式比较不同动作对可恢复性、有效选择与不可逆后果的影响，并说明模型、情景、时域、约束、成本及评价标准。C17 本身是候选决策原则，不提供安全保证；LK5 同样是需要另外验证的候选规则，不能据此直接规定动作方向，也不能认定审查后保留的方案都可恢复。C17 还指出，是否允许预先排除某些选项，需要验证适用边界、误排后果和替代路径，这一要求同样适用于 LK5。
- 在时间很短、无法现场估计的情况下，相关的比较需要事先完成，并转化为带适用条件、失效信号和修订入口的简洁规则（[《简化与退路》](https://sl-knowledge.github.io/knowledge-site/framework/foundations/simplicity-and-recovery) SF6）。

## 七、几种表现

同一结构在不同领域有不同的样子。以下只作说明，不作具体分析：

| 情境 | 日常表现好、可能留有恢复缺口的方案 | 日常表现较差、恢复能力较强的方案 |
|---|---|---|
| 资源安排 | 资源集中用于当前产出：日常利用率较高，但特定扰动可能耗尽恢复所需的资源 | 为恢复保留资源：日常利用率可能较低，但在指定扰动下仍可能保留恢复路径；效果取决于资源能否调用及其他约束 |
| 组织与供应链 | 去掉冗余、极致精简：平常成本最低，一个环节中断就可能全面停摆 | 保留缓冲与备选：平常成本更高，但中断时还能周转 |
| 生态系统 | 长期看似平静，但吸引域在缩小、韧性在下降 | 波动更多，但能承受更大的冲击 |

## 八、与前人工作的关系

| 前人工作 | 核心内容 | 本文的关系与补充 |
|---|---|---|
| Holling（1973）；Ludwig、Walker、Holling（1997） | 区分稳定性与韧性；系统可以保持局部稳定，同时吸引域缩小、韧性下降 | LK3 的来源之一。本文把它从"系统怎样演变"转到"方案怎样被选出" |
| Carlson 与 Doyle（1999）"高度优化容忍" | 对预期扰动的优化，可能伴随对未预期扰动的脆弱性 | 支持 LK3 的方向。它不证明 p 与 q 普遍反向变化，本文也不作此主张 |
| 赌徒破产问题；Taleb 等（2014）关于毁灭性风险；Peters（2019）关于遍历性 | 存在吸收态或不可恢复损失时，平均收益不足以单独评价长期过程；还需检查进入这些状态的概率与后果，并区分时间平均与总体平均 | 支持 LK1 中单独评价锁定概率与后果 |
| Arrow 与 Fisher（1974）关于不可逆决策 | 不可逆的决策在不确定下具有额外代价，保留选择余地有价值 | 与 LK5 的方向一致 |
| 分岔与临界转变研究（如 Scheffer 等，2009）；受控系统失控的分岔分析（Kwatny 等；Gill 等，2013） | 越过分岔或阈值后，系统落入另一个吸引子 | 为 LK2 中"阈值加正反馈"一类锁定提供可选的数学表达与估计方法，只适用于具备相应结构的系统 |

**本文的补充**主要在两点：

1. 把日常表现、出问题的概率、出问题后的锁定概率与后果明确分开，并给出它们之间的关系与限制（LK1—LK3）；
2. 用这些量重新表述 SF9 的筛选与保留机制，并指出从"缺口可能被保留"到"选择过程偏向这类方案"还需要哪些条件（LK4）。保留机制本身已由 SF9 讨论，不是本文的新增。

**与本站其他文章的关系：**

- [《不确定世界中的行动》](https://sl-knowledge.github.io/knowledge-site/framework/book/acting-under-uncertainty)：不可恢复损失要单独定义；同样的成功概率可以对应不同的损失与恢复时间。
- [《简化与退路》](https://sl-knowledge.github.io/knowledge-site/framework/foundations/simplicity-and-recovery)：SF2（运行成本降低不单独保证恢复范围扩大）、SF6（简洁规则须保留适用条件、失效信号和修订入口）、SF9（有限情景筛选可能留下恢复缺口）。LK3 可以看作 SF2 的一种常见表现；LK4 用本文的量重新表述 SF9 的筛选与保留机制（9.2、9.3），并补充产生选择偏向所需的条件。
- [《控制权、信息与时间》](https://sl-knowledge.github.io/knowledge-site/applications/viability-first-control) v0.2.1：C7（"保持"可能在消耗到达终点所需的资源）、[C17](https://sl-knowledge.github.io/knowledge-site/applications/viability-first-control#c17)（不确定性下显式比较可恢复性与未来选择，候选原则）、C18（在规则层面检查联合约束冲突）。LK5 是与 C17 方向一致的候选筛选规则。

## 九、可检验的推论

<a id="lk6"></a>

> **LK6　若 LK4 所述机制成立，在其条件满足的系统中，应当能观察到以下现象。检验需要完整的运行记录，而不只是事故记录。**

1. **按日常表现筛选的方案，在少见扰动下的锁定比例较高**。比较时需要：各方案被采用的次数、没有出事的运行记录，以及可比的扰动暴露量。只看严重事故中的方案，不足以检验这一点。
2. **改变筛选依据的效果**。若检查确实识别了恢复缺口、存在并实际采用可行的替代方案，且在相同 A 与可比的扰动强度、初始条件和暴露口径下，该方案降低了 q，则经 A 进入锁定的发生率应降低。若替换同时改变 p，必须比较 p q；若还存在未经 A 的锁定路径，还需比较第二节的完整分解。不能仅凭检查有区分力、存在替代方案，就推出全部锁定事件减少。有限样本中的事件总数也不保证下降，应比较相应的发生率与不确定性。检验条件、替代方案与评价指标应事前记录。
3. **修订速度的作用**。若反馈能够识别相应缺口、替代方案确实减少该缺口且能及时实施，那么更快完成修订的系统，缺口被长期保留的比例应当更低。仅有更快的触发信号，或引入另一种缺口的替换，不足以支持这一预测。

**会削弱本文的情况：**

- 在可比的暴露条件下，按日常表现筛选的方案并不比其他方案更容易被锁定；
- 在检查有效、替代方案已实际采用且其降低 q 的判断得到独立支持、初态与扰动暴露可比的条件下，经 A 的锁定发生率长期未呈现预期下降；这会削弱所采用的模型、测量或机制判断，需要检查而非事后修改评价口径；
- LK4 的四个条件都成立时，仍观察不到选择偏向。

## 十、知识地位与局限

| 内容 | 本文的地位 |
|---|---|
| 把日常表现、p、q、s 分开评价（LK1） | 事件与评价量的定义是分析约定；概率分解是基本概率恒等式，不是新定理 |
| 锁定的定义（LK2） | 分析约定；"阈值加正反馈"是其中一类机制 |
| 日常表现好不说明 p、q 低；提升日常表现的改变可能提高 q（LK3） | 候选机制，有前人的对应观察 |
| 用 p、q、s 重新表述 SF9 的保留机制，及产生选择偏向的条件（LK4） | 对已有机制的重新表述，加上候选条件 |
| 以 P(L) 作约束、优先审查高 q 方案（LK5） | 待验证的候选筛选规则，依赖额外的价值判断 |
| 第九节的推论（LK6） | 待检验 |

**局限：**

1. **q 与 P(L) 往往难以估计**，需要领域知识、数据与明确的定义。
2. **不是所有失效都表现为锁定**，也不是所有锁定都来自阈值加正反馈。
3. **改变筛选依据有代价**，可能提高日常成本或引入新的风险，需要具体比较。
4. **本文来自对少数情形的讨论**，作为独立原则的价值仍需更多领域的检验。

> **平稳的记录，不是恢复能力的充分证据。可恢复的边界可能已经越过，只是日常表现尚未显露；还有没有退路，需要另行检查。**
