> **公开整理版 v0.1 · 价值论与研究治理。** 根据同题研究笔记整理，保留“目标不能持续破坏其承载条件”“为未来保留选择与纠错能力”的主线，补充事实与价值的区分、受影响者的地位，以及目标制定与修订程序。本文提出可以讨论和反驳的规范立场，不把它作为从物理定律唯一推出的社会最优目标。

## 一、目标函数为什么也需要解释？

研究复杂系统时，我们常问：怎样提高效率，怎样维持稳定，怎样加快知识积累，怎样扩大未来选择？这些问题已经预设了什么值得追求。若目标本身没有被讨论，再强的预测和优化，也可能只是把系统更有效地推向一个值得怀疑的方向。

这里把“目标函数”用作广义说法，指我们比较行动和结果所依据的目的与评价方式，不要求所有价值都能写进一个数值公式。实际问题可能同时包含多个目的、不可突破的限制，以及尚未解决的分歧。

至少需要区分三种合理性：

| 层次 | 要回答的问题 | 尚不能据此回答什么 |
| --- | --- | --- |
| 可行性 | 在资源、时间和现实条件下能否做到？ | 做得到是否就值得做？ |
| 手段合理性 | 给定目标，行动是否有助于实现它？ | 目标本身是否正当？ |
| 目标与程序的正当性 | 为什么追求这个目标，谁受影响，谁有权决定？ | 不能只靠计算效率或既有权力给出答案 |

一个方案可以可行、有效率，却仍然不公正；一个值得追求的目的，也可能因手段不当或现实条件不足而不能照原计划执行。讨论目标函数的合理性，需要把这些问题连起来。

## 二、生存条件能提供约束，不能替我们完成价值选择

人有身体、恢复需要、依赖关系和有限时间。持续的社会活动也依赖资源、生态条件与协作。如果一个方案长期耗尽它赖以运行的条件，就可能无法实现它自己承诺的长期目标。

这是对可持续性的检查。例如，一个以长期学习为目的的安排，若持续占用学习者全部休息和生活资源，就需要解释它如何维持。这个问题可以用观察和证据检验。

但“某个系统能够持续”与“它值得维持”是不同判断。一个伤害部分人的安排，也可能在一段时间内稳定运行。不能把稳定本身当作道德证明，更不能只因为压迫可能妨碍长期效率，才承认受影响者值得尊重。

从事实转到应当，需要说明新增的价值前提。[休谟在《人性论》第三卷第一部第一节末尾](https://davidhume.org/texts/t/3/full)提出过这类推理转换问题。这里借此要求自己的论证交代依据，并不试图在本文解决全部元伦理学争论。

因此，本篇明确接受一个规范起点：**受影响的人应当作为有自身生活与目的的主体被认真考虑，其基本尊严与参与能力不能仅以他人目标下的产出衡量。** 生存事实约束实现方式，这个价值起点则说明我们为何关心人的处境。

## 三、为谁做优化？不能用“整体”掩盖不同的人

目标取决于研究对象，也取决于谁被纳入评价。组织管理者、投资者、技术开发者、使用者和其他受影响者，可能面对不同收益与成本。

描述某个主体追求什么，不等于认可其目标正当。即使一个目标很符合决策者的利益，也仍需回答它如何影响别人，以及为什么别人应当接受。

“为了社会整体”同样需要展开：哪些人得到好处，哪些人付出代价，代价是否集中在缺少表达能力的人身上？谁决定当代与后代的权重？不确定的未来收益，可以为今天的哪些负担辩护，证据和限度在哪里？

因此，不能把社会当作拥有单一意志的人，也不能把整体存续自动置于每个人的生活之上。目标的合理性，包含如何处理人与人之间的冲突、如何分担成本，以及如何保护异议。

原笔记谈到代际延续。在这里，它指维护后代能够生活的条件，以及支持人们自主作出家庭和生育选择；不能从社会延续需要推出每个人都有生育义务。

## 四、指标可以帮助判断，但不能悄悄取代目的

产出、技术性能、稳定程度、满意度或机会数量，都可能提供有用信息。问题发生在它们被当作全部目的，而影响解释的其他差异被排除。

原笔记用GDP、技术、稳定、平等、自由和幸福举例。公开稿把这些表述限定为风险提示：追求某种价值时，如果忽略相关条件、代价和分配，可能产生与原初目的冲突的结果。这不是说每一种单一目标都必然导致灾难，也不是说把指标增加到足够多就能避免问题。

| 看到的改善 | 还应继续检查什么 |
| --- | --- |
| 总产出增加 | 成本、生态条件、时间负担与收益分配怎样变化？ |
| 技术性能提高 | 谁能使用，谁承担转型成本，人的判断能力是否得到支持？ |
| 表面秩序更稳定 | 异议能否表达，错误能否被发现，必要改变能否发生？ |
| 可选项目变多 | 人是否有实际能力进入、退出并承担后果？ |
| 平均满意度提高 | 哪些群体的处境被平均数掩盖，评价方式是否可靠？ |

这些问题可以暴露指标的盲区，但不自动给出最终权重。价值冲突需要被明确讨论，不能藏在一个看似中性的综合分数里。

## 五、长期开放性：值得辩护的方向，而非普遍最大化定理

原笔记提出“长期有效选择空间”。我保留这个方向：**在尊重人的基本地位、维持必要生活与生态条件的前提下，重视人们未来学习、行动、调整和重新选择的实际能力。**

理由是有限知识与未来不确定性。今天的决策者未必知道以后最好的生活形态；保留纠错与重新选择的能力，可以减少一次判断替所有人永久定下道路的风险。

这里的“有效”很重要。一条路径若没有资源、时间、信息或实际进入条件，就不能仅因写在清单上而算作有意义的机会。类似的评价方向，可以与[阿马蒂亚·森《Equality of What?》中对基本能力的讨论](https://ophi.org.uk/sites/default/files/Sen-1979_Equality-of-What.pdf)对照。本文的具体框架仍需自行辩护，不能借一个相近概念取得现成结论。

开放性也有成本。学习需要投入，关系需要承诺，一些重要工作只有持续专注才能完成。为了永远不关掉任何选项而拒绝承诺，反而可能损害生活与能力。

因此，这里不主张最大化选择的数量，也不把未来开放性当作唯一价值。它应与当下生活、平等地位、责任和有理由的承诺共同考虑。[《自由与逍遥》](./freedom-and-future-options.md)讨论的正是这种区别：知道自己仍有路，并不要求不断更换正在走的路。

## 六、人的尊严为什么不能只作为“系统有用的变量”？

人的体验和判断会影响协作与行动，这是值得研究的经验问题。但若只因为尊严有助于合作，才把它纳入目标，人就仍可能在“暂时没用”时被排除。

本篇的规范立场更进一步：人不应仅因能够贡献产出而得到承认。即使某种不尊重人的做法在模型中显得有效，它仍然需要面对关于人的地位、选择和正当性的反对。

[康德《道德形而上学奠基》第二节](https://www.gutenberg.org/files/5682/5682-h/5682-h.htm)将人同时作为目的、而非仅仅作为手段的思想，是相关的哲学参照。本文没有从这一思想直接推出完整制度方案，但借此拒绝把人只当作增长、稳定或技术目标的投入品。

这也不意味着任何公共安排都不能要求贡献或承担成本。需要说明的是理由、分配、授权与限度，并给受影响者留下表达、质疑和纠正安排的实际渠道。把成本说清楚，比用宏大目标抹去它更接近负责的决策。

## 七、谁在选择，按什么标准，反馈是否真实？

目标合理性的讨论，最终要回到制定和修订过程。专业知识可以帮助比较后果，但专业能力本身不授予替所有人决定目的的权利。一次征询意见，也不自动证明所有人的处境都被充分考虑。

需要持续追问：谁提出目标，谁设置权重，谁能够反对？谁承担错误的后果，谁掌握核查资料？负面反馈能否进入决策，还是只留下支持原方案的记录？

“反馈真实”至少包含两层。事实层面，要有来源、测量口径和独立核查，允许发现效果不如预期。程序层面，要让受影响者能够表达原指标遗漏的损失，并能质疑评价方式本身。

经验结果可以说明一个方案是否达成了承诺、遗漏了什么代价；它不能单独裁决所有价值冲突。即使某个方案达成了目标，人们仍可能有理由反对那个目标或分配方式。

目标制定也因此不能结束于“请相信制定者”。它需要可解释的理由、受影响者的参与、能够提出异议的条件，以及修订、停止和追责的安排。这些是本文主张的程序要求，其具体形式应随问题和参与者条件进一步设计。

## 八、把价值立场写成可以被质疑和修订的记录

一个有用的目标说明，不必先写成优化公式。可以先留下这样一份记录：

| 项目 | 必须说明的内容 |
| --- | --- |
| 目的 | 我们希望改善什么，为什么值得？ |
| 受影响者 | 谁获益、谁承担成本，哪些人可能被遗漏？ |
| 价值前提 | 接受哪些原则，仍存在哪些分歧？ |
| 现实条件 | 资源、时间、生态与执行条件是什么？ |
| 评价与证据 | 指标测到什么，测不到什么，怎样核实？ |
| 替代方案 | 为什么选择当前安排，其他选择付出什么代价？ |
| 更新与责任 | 什么结果要求修改、停止或重新讨论目标，由谁处理？ |

**虚构例子：成人学习项目。** 如果目标写成“提高结课数量”，组织者可能完成统计要求，却不知道参与者能否把所学用于自己的生活。若把目标改为“支持参与者获得自己有理由重视的实际能力”，则需要继续询问参与者想改善什么，比较时间和费用负担，检查真实应用，并保留退出与调整课程的条件。

但第二种表述本身也不能保证项目成功。组织者仍可能替参与者规定什么值得重视，也可能用新的能力分数重复旧问题。因此，参与和反馈需要落到实际安排，项目效果与价值分歧也要分别报告。

原笔记提出：目标不应摧毁实现它的主体。公开稿把它保留为对长期目标的一项一致性检查，同时补上一层更重要的要求：即便一个目标能够自我维持，它也必须说明为什么值得、由谁决定，以及如何对待承载它的人。

本篇选择以人的基本地位、实际能力和未来纠错机会为价值起点。这是一项需要公开辩护的承诺。接受它之后，再用现实证据约束手段、检验承诺，并让受影响者参与修订目标，才是本文所说的合理性。
